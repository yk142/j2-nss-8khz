# 要件定義（ドラフト）— 弾性 J2（4 状態）への加速度状態 NSS の拡張

作成: 2026-10-28 / 状態: **§7 を決定（推奨案）。実装・実験中**

前提: 剛体の加速度状態 NSS（#45 基本形、#46 ノイズ学習、#49 ロールアウト損失。`docs/nss_resid_state_results.md`、`nss_acc_noise_results.md`、`nss_rollout_loss_results.md`）、弾性 NSS の要件と結果（`docs/requirements_nss_flex.md`、`flex_nss_main_results.md`）、ゲイン最適化（`docs/gain_opt_results.md`）。

## 1. 目的

剛体で、物理を使わない加速度状態 NSS（ノイズ学習）が、純 NN の A を上回り、残差型 B に近づいた。**弾性（二慣性）で同じ結論になるか**を、現行の弾性 NSS（B 幅 64、A 幅 64）と同じゲートと用途（C4 のゲイン最適化）で比べ、どのアーキテクチャが有利かを判断する。

## 2. 剛体での比較（この issue の動機、幅 64 の B と幅 256 の A は #16、acc は #46・#49、3 シード平均）

| 項目 | #16 B 幅 64 | #16 A 幅 256 | #46 ノイズ σ = 1.0 | #46 + ロールアウト K = 16 |
|---|---|---|---|---|
| 物理の事前知識 | 解析モデル | なし | なし | なし |
| パラメータ数 | 8,769 | 133,121 | 8,705 | 8,705 |
| (a) test（≤ 1.0） | 0.494 | 0.547 | 0.446 | 0.464 |

読み取り: 物理を使ってよいなら B 幅 64 が精度で最良。物理を使わない純 NN どうしでは、ノイズ学習の acc 状態が A 幅 256 より、(a)(b) が良く、パラメータ約 1/15、(d) 約 6 倍、学習時間約 1/6。(c) は同等。

この比較で言えないこと: 弾性・ゲイン最適化は未評価。異なるゲインでの再現性は両者とも未評価。B は解析モデルが外れる条件で不利になる可能性があり、acc 状態は解析モデルに依存しない（ただし acc の初期値は解析モデルから作る）が、どちらも未検証。

## 3. アーキテクチャ（案）

剛体版（状態 acc、入力 `[acc, τ, q, dq]`、出力 Δacc、速度は前進オイラー・位置は台形則）を、二慣性へ拡張する。

| 変数 | 次元 | 内容 |
|---|---|---|
| 状態 acc | 2 | `[ddθ_{k-1}, ddθm_{k-1}]`（直前の区間のリンク・モータ加速度。現行データの `Y[k-1]`） |
| 入力 | 5 | `[τ, θ, dθ, twist, dtwist]`（`X_raw`）。ねじりは `s_tw`、`s_dtw` で標準化（現行の弾性 NSS と同じ） |
| NN の入力 | 7 | `[acc(2), τ, θ, dθ, twist, dtwist]`（標準化） |
| 出力 | 2 | `Δacc`（リンク・モータ）。`acc_{k+1} = acc_k + Δacc`、最後の層は 0 初期化 |
| 積分 | | 速度は前進オイラー、位置は台形則（リンク・モータとも）。ねじり = θm − θ |

- 学習の損失は 1 ステップ。ノイズ学習（入力 acc に σ_L、σ_m）と、ロールアウト損失（案 1: K = 16）を、剛体と同じ形で入れる。
- 各シナリオの最初の遷移（step = 0）は除く。データは現行の `j2_nss8kflex.h5`（再生成なし）。
- 実装は `python/nss8kacc/` を弾性に拡張（`python/nss8kaccflex/`、または `nss8kacc` の一般化）。評価は `python/nss8kflex/evaluate_lib.py`（(a)〜(d)、(c3)）を再利用する。

## 4. 実験（案）

幅 64。シード 0 で絞り、有望なものを 3 シード。

| 記号 | 構成 |
|---|---|
| F0 | 基本形（σ = 0） |
| F1 | ノイズ学習。σ は剛体の σ = 1.0 rad/s² を基準に、ddθ と ddθm の標準偏差の比に合わせてスケール。0.5 倍、1 倍、2 倍を掃引 |
| F2 | F1 の最良 + ロールアウト K = 16（案 1） |

比較対象（既存）: 弾性 B 幅 64、A 幅 64（`reports/issue-37/`、3 シード）、解析モデル。

## 5. 評価

- ゲート (a)〜(d) と (c3)（`requirements_nss_flex.md` §5 と同じ。(a) は参考値、(b) は θ ≤ 0.4° かつねじり ≤ 解析モデルの 2 倍）
- **ゲイン最適化（#39 と同じ）**: NSS の最適ゲインが真値でも安定、後悔 ≤ 10%、最適点での J の相対誤差 ≤ 15%、シード間の最適 wn のばらつき ≤ 10%。真値の評価は #39・#41 の結果を再利用する（追加の Simscape 実行は、新しい最適点が既存の 35 点に含まれないときだけ）
- 学習時間、パラメータ数、(d)

## 6. 判定

- 「acc 状態が有利」: (b)(c)(c3) が B 幅 64 と同等で、かつ解析モデルに依存しない利点（または速度）が示せる場合
- 「B が有利」: acc 状態が (b) のねじり、(c3)、ゲイン最適化のいずれかで B に劣る場合
- 「A の置き換え」: acc 状態が B には届かないが A 幅 64 を上回る場合（純 NN が必要な場面では acc 状態を使う）

## 7. 決定事項（2026-10-29、推奨案で進める）

1. 入力の位置の表現: 生の `θ` と `twist`（`dθ`、`dtwist` を含む 7 列）。弾性の既存モデルは `sin θ, cos θ` だが、剛体では `sin, cos` に効果がなかったので、剛体の基本形に合わせて生の θ にする
2. ノイズ σ: 列ごとの Δacc の標準偏差の `r` 倍（`--acc-noise-rel r`）。弾性の Δacc の標準偏差は ddθ 0.181、ddθm 0.408 rad/s²（剛体は 0.203）。剛体の σ = 1.0 rad/s² は約 4.9 倍に当たるので、`r` = 2.5、5、10 を掃引する
3. 評価にゲイン最適化（C4）まで含める。真値の評価は #39・#41 を再利用する
4. 実装は新規の `python/nss8kaccflex/`（`nss8kflex` の評価ライブラリは再利用。状態を持つモデルのため、ロールアウトの先頭で `reset()` を呼ぶ `fresh()` を `evaluate_lib.py`・`c4.py` に足した）
