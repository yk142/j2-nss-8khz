# 要件定義（ドラフト）— 弾性 J2 の NSS（4 状態）

作成: 2026-10-24 / issue #29 / 状態: **確定（2026-10-24、§7 の 1・2 をユーザーが承認。3 は案のまま）。2026-10-26 に §5・§8 を更新（#43）**

前提: 弾性プラント（#21 `docs/flex_plant.md`）、モータ角 PD の閉ループ（#23 `docs/flex_loop_results.md`）、評価条件 C4（#25 `docs/flex_eval_results.md`）、不安定化の原因（#27 `docs/delay_vs_resonance.md`）。

## 1. 目的と用途

オフラインで、**1 kHz・1 ms 遅れのモータ角 PD** のゲインを最適化し、制振性能を事前評価する。NSS は弾性 J2 の 8 kHz モデルで、真値は Simscape の二慣性プラント。

#25・#27 で分かったこと: 剛体の NSS でゲインを選ぶ意味が出るのは、**弾性モードと遅れの組み合わせによる不安定境界**が現れるとき。NSS が再現すべき最重要の性質は、この境界の位置と、境界の内側での追従の順位。

## 2. 状態・入出力

| 項目 | 案 | 理由 |
|---|---|---|
| 状態 | (θ, dθ, θm, dθm)（リンク角・角速度、モータ角・角速度） | 二慣性。ねじり = θm − θ |
| 入力（モデルへ） | `sin θ`, `cos θ`, `dθ/5.236`, `twist/s_tw`, `dtwist/s_dtw`, `τ/860.4` の 6 列。twist = θm − θ、dtwist = dθm − dθ。`s_tw`, `s_dtw` は train の標準偏差 | ねじりは 1e-3〜1e-2 rad と小さく、正規化しないと学習できない |
| 出力 | `ddθ`, `ddθm` の 2 列（8 kHz の差分 `Δ(dθ)/Δt`, `Δ(dθm)/Δt`） | 剛体版（1 列）の拡張 |
| 更新 | オイラー: `q1 = q + Δt·dq`、`dq1 = dq + Δt·ddq`（リンク・モータとも）、Δt = 125 µs | 剛体版と同じ |
| トルク入力 | モータ側のトルク τ（区間先頭の瞬時値） | 剛体版と同じ |
| 出力の標準化 | (A) 純 NN: `ddθ` と `ddθm` を固定定数（τ_peak/JL、τ_peak/Jm）で割る。(B) 残差型: 残差を train の標準偏差で割る | 2 出力の大きさが違うため、列ごとに標準化 |

q と θm を別々に積分するとねじりの誤差が積み上がるので、**評価はねじりの誤差も別に見る**（§5）。

## 3. 残差型 (B) の解析モデル

二慣性の運動方程式（`docs/flex_plant.md`）:

- `JL·ddθ = k·twist + c·dtwist + mgL·sin θ − Bv·dθ − Fc·tanh(dθ/ε)`
- `Jm·ddθm = τ − k·twist − c·dtwist`

(B) は `ddθ = a_phys,L + NN`、`ddθm = a_phys,m + NN` とし、最後の層を 0 初期化する（開始点は解析モデルそのもの）。摩擦はリンク側に置く（`docs/flex_plant.md` と同じ）。

## 4. データ

### 4.1 シナリオ

剛体版 `nss8k`（328 本、19.4 M 遷移）と**同じシナリオ表・シード・split**を使い、真値だけを弾性プラントに置き換える（比較しやすい）。

### 4.2 弾性プラントに合わせて変える点

| 項目 | 剛体版 | 弾性版 | 理由 |
|---|---|---|---|
| 励振のソフトリミットバリア | リンク角のフィードバック | **モータ角・モータ角速度のフィードバック**（デッドゾーンの帯と Kp, Kd の式は同じ） | リンク角のフィードバックは wn ≳ 7 で不安定（`docs/requirements_flex_loop.md` §1） |
| 姿勢保持・PTP の閉ループ | リンク角 PD、wn = 30、ζ = 1、8 kHz | **モータ角 PD**、wn = 30、ζ = 1、8 kHz、FF は `j2FeedforwardFlex`（#23 と同じ） | 同上 |
| 初期状態 | (θ0, dθ0) | (θ0, dθ0, twist0 = 0)、モータ側は剛体極限の整合する値 | 励振開始時の過渡を避ける |
| 学習対象の追加 | なし | **足さない**（§7 の 1）。C4 は評価専用で、NSS を閉ループに接続して走らせる | NSS は制御器によらずプラント（τ → 加速度）を学ぶ |

接触は剛体版と同じく生成しない。

### 4.3 規模

- 遷移数は 19.4 M（剛体版と同じ）。生成時間は剛体版の約 4 時間より長い見込み（二慣性は Simscape の状態が増える）。小さい preset（`nss8k_small`）で時間を実測してから確定する
- double 保存、キャッシュは `data/cache/nss8kflex_<name>.mat`（剛体版と分離）

### 4.4 検証（生成後）

NaN なし、|τ| ≤ 860.4 N·m、|dθ| の上限、ねじりの上限（飽和・破綻の検出）、シナリオ表の一致、**二慣性の解析モデルとの 1 ステップ整合**（残差 RMS が剛体版と同程度）。

## 5. 評価ゲート（案）

| ゲート | しきい値（案） | 測り方 |
|---|---|---|
| (a) 1 ステップ（**参考値**、2026-10-26 更新） | 合否には使わない。二慣性の解析モデルの RMSE との比を記録する（旧案: 1.0 倍以内） | `ddθ`, `ddθm` の RMSE |
| (b) 窓の開ループ | 4,000 ステップ窓で θ RMSE ≤ 0.4° かつ**ねじり RMSE ≤ 解析モデルの 2 倍**（約 2.6e-4 rad。2026-10-26 確定） | 記録トルクを再生して自己回帰 |
| **(c) PTP 閉ループ（主）** | モータ角 PD（8 kHz、wn = 30、ζ = 1）で、PTP 12 本が発散せず、θ RMSE ≤ 0.1°。真値とのねじり RMS の差も記録 | 剛体版と同じ方法を弾性用に拡張 |
| **(c3) C4 の再現（制振の主）** | C4（1 kHz・1 ms 遅れ）の 21 ゲインで、(i) **安定／不安定の判定が真値と一致**（持続振動の有無）、(ii) 安定なゲインで J の順位の Spearman ≥ 0.9 | #25 の評価スクリプトと同じ指標。NSS は 6 本の PTP で走らせる |
| (d) スループット | ≥ 145,000 ステップ/s（剛体版と同じ。出力が 2 列に増えるため、満たさなければ幅を下げる） | バッチ並列ロールアウト |

(c) が通らなければ他が通っても不合格。ただし (c) は弱いゲート（(a) が解析モデルの 20〜50 倍悪くても通る）なので、モデルの良否は (b) のねじりと (c3) で見る（`docs/c3_sensitivity_results.md`）。(c3) は制振評価に使えるかの判定で、通らなければ「弾性 NSS はゲイン最適化に使えない」と結論する。

## 7. 決定事項（2026-10-24）

1. **遅れ付き PD のシナリオは学習データに足さない。** 学習は、モータ角 PD（8 kHz）の姿勢保持・PTP と励振だけ。C4 は評価専用（NSS を閉ループに接続して走らせ、真値と比べる）
2. **データ生成時の FF は今のまま**（`j2FeedforwardFlex`、トルクは剛体の逆動力学）。C4 の評価と一致させる
3. (c3) のしきい値は案のまま（安定／不安定の判定が全 21 ゲインで一致、安定ゲインの J の Spearman ≥ 0.9）。実測後に見直しうる

## 8. 更新（2026-10-26、#43）

根拠: #34（`docs/c3_sensitivity_results.md`）、#37（`docs/flex_nss_main_results.md`）、#39・#41（`docs/gain_opt_results.md`、`docs/gain_opt_wide_results.md`）。

1. **(a) は参考値に下げた。** 解析モデルの係数を 1 つずらした感度実験で、(a) の倍率は (c3) の合否を決めないと分かった（Bv ×0.5 は (a) 2.2 倍でも (c3) 良好、Jm ×1.1 は (a) 7 倍で判定が 2 組外れる）。本学習の 12 本は (a) も合格したが、判定の考え方として維持する
2. **(b) のねじり RMSE の閾値を、解析モデルの 2 倍（約 2.6e-4 rad）に確定した。** 感度実験で、約 2e-4 以下なら (c3) はほぼ無傷、3.4e-4 以上で判定の外れか ρ の悪化が出た。A・B は解析モデルの 0.5〜0.6 倍
3. **採用モデルは B（残差型）幅 64。** 12 本すべてが (a)〜(d)・(c3) に合格。B はシード間のばらつきが小さく、幅 128 より約 1.8 倍速い。A 幅 64 も合格したが、(a) のばらつきが大きい
4. **最適化用途の合格基準（#39・#41 で使用）:** NSS の最適ゲインが真値でも安定、後悔 ≤ 10%、最適点での J の相対誤差 ≤ 15%、シード間の最適 wn のばらつき ≤ 10%。結果は B・A とも合格（後悔 0%、相対誤差 0.9〜6.6%）。負の対照（k ×0.9）は後悔 305% で、この検証が誤ったモデルを見抜くことを確認した。安定境界の位置の基準は対照を弾けず、判別には後悔と相対誤差が効く
5. 未評価: 遅れの大きさ・共振周波数・k のずれを変えた条件（ロバスト最適化）
