# 要件定義（ドラフト）— 8 kHz NSS 用の接触なしデータ

作成: 2026-10-22 / issue #5 / 状態: **確定（2026-10-22、§7 の 4 点をユーザーが承認）**。

`docs/handover.md` §5 の未決事項 1〜3 を詰めた案。根拠の数値は、フォーク元の 8 kHz 生データ（接触なし 20.2 M サンプル。`nearlimit` の 0.8 M を含む）を実測したもの（§6）。学習設定（未決 4）は対象外。

## 1. 接触なしの絞り方

**シナリオ単位でパターンを除外し、サンプル単位では検証だけ行う。**

| 項目 | 方針 | 根拠 |
|---|---|---|
| `contact_fall` / `contact_drive` / `contact_bln`（56 本） | **生成しない** | 接触専用シナリオ |
| `nearlimit`（10 本） | **生成しない** | 接触はしない（リミットから 0.1° 以内のサンプルは 0%）が、目的が「リミット近傍」で、PTP 範囲（−124.5°〜+31.5°）の外。自由運動の力学は他のシナリオで足りる |
| 残りのパターン | 励振 7 種、姿勢保持 7 姿勢、PTP は**フォーク元と同じシード・同じ条件**で生成 | 接触なしの 15 パターンは、いずれもリミットから 0.1° 以内に入らない（実測） |
| `atLimit` 除外 | 不要になるが、**検証として残す**（全サンプルで 0 件であることを `validateJ2Data` で確認。1 件でもあれば失敗） | 接触が混入していないことの保証 |
| バリア | 励振は従来どおり位置 85%・速度 60% のソフトバリア | 接触シナリオだけがバリアを外す設計だった |
| 近傍フラグ | リミットから 1° 以内の遷移に `nearLimit` を付けるだけで除外しない（**実測 942 件、全体の 0.005%**。当初は 0 件の見込みだったが、すべて `hold_+060`（+側のリミット近傍の参照）。接触（0.1° 以内）は 0 件） | |

結果: 生成するのは 328 本（フォーク元の 394 本 − 56 − 10）。内訳は学習系 316 本（train/val/test）＋ PTP 12 本。
フォーク元の 8 kHz キャッシュと**ビット一致する**はずなので、新規生成の結果はそれと照合して再現確認とする（§5）。

## 2. シナリオ設計と規模

フォーク元の接触なし分をそのまま使う。変えるのは保存形式と、8 kHz 用の分割・検証のみ。

| 種別 | パターン | 本数 | 長さ |
|---|---|---|---|
| 励振 | `bln_normal` / `bln_high` / `bln_low` / `freefall` | 60 / 30 / 30 / 6 | 10 / 5 / 15 / 3 s |
| 励振 | `chirp` / `step` / `micro` | 10 / 20 / 20 | 20 / 2 / 10 s |
| 姿勢保持 | `hold_±…`（7 姿勢） | 7 × 20 | 5 s |
| ベンチマーク | `ptp_v20/40/60/80` | 4 × 3 | 最大 60 s |

- **規模**: **19,397,480 遷移**（PTP 約 0.53 M を含む。学習系は約 18.9 M）。当初見積もりの 20.2 M は `nearlimit` 0.8 M を含む数字だった。生成は約 4 時間（実測 23:55〜03:53、ワーカー 1 本、実時間の 5〜6 倍）。
- **間引きで量を減らす余地**: 8 kHz の隣接サンプルはほぼ重複する。必要なら、学習時に遷移を一様に 1/k に間引く（生成は減らさない）。
- **新設・変更**:
  1. 8 kHz 生データは **double で保存**（single だと q の丸め 6e-8 rad が、2 次の項 0.5·Δt²·ddq ≈ 1e-6 rad の 6% に達するため。容量は約 2 倍の 430 MB で問題なし）。
  2. 8 kHz 版のプリセット名は `nss8k`。キャッシュ `data/cache/nss8k_<name>.mat` に分離し、フォーク元のキャッシュと混ぜない。
  3. split は従来のパターンごと 70/15/15 を踏襲（シードも同じ）。ベンチマークは評価専用で学習に混ぜない。
- **追加しないもの**: 離散制御器（ZOH）に由来するシナリオは追加しない。姿勢保持・PTP の PD は連続形（wn = 30 rad/s）を 8 kHz で評価しており、NSS を閉ループに入れたときと入出力のタイミングが一致する（x_k → τ_k → x_{k+1}）。

## 3. 入出力の定義

| 項目 | 案 | 理由 |
|---|---|---|
| トルク入力 `u_k` | **区間先頭の瞬時値 τ(t_k)**（区間平均は使わない） | 制御器は x_k から τ_k を出して 125 µs 保持する構造で、因果的。平均（τ_k+τ_{k+1})/2 は τ_{k+1} を要し、閉ループで使えない |
| トルクのステップ内変化 | **許容する。誤差の下限として記録** | τ_k を保持と見なした場合の ddq の差は RMS 0.088 rad/s²（`step` のみ 0.59）。1 kHz 版の目標精度 0.3 rad/s² に対して無視できないが支配的ではない。評価では「トルク起因の下限」として別掲する |
| 角度 `q` の入力 | **`sin q`, `cos q`** の 2 入力 | 重力が `sin q` で、可動域（223°）が 360° 未満なので一意。生の q でも情報は同じだが、純 NN (A) が重力を学びやすい。**生 q との比較は学習フェーズで行う**（暫定） |
| 角速度入力 | `dq / 5.236` | 最大角速度で正規化 |
| トルク入力の正規化 | `τ / 860.4`（瞬時最大） | フォーク元の `spec` 形式と同じ |
| 出力 | `ddq_k = (dq_{k+1} − dq_k) / Δt`、Δt = 125 µs | 加速度。評価は rad/s² で行う |
| 更新 | `dq1 = dq + Δt·ddq`、`q1 = q + Δt·dq`（オイラー） | 決定事項 2 の `x1 = x + dx` |
| 出力の標準化（純 NN (A)） | **固定定数 `τ_peak / M = 141.4 rad/s²` で割る** | 接触を除くと外れ値がなく、全体の標準偏差は 13.9 rad/s²。固定定数なら (A) と (B) で単位がそろい、他のデータでも再現できる |
| 出力の標準化（残差型 (B)） | **接触なしの残差の標準偏差**（学習データから算出、保存） | フォーク元で問題だった「接触の巨大な残差が標準偏差を支配する」状況（32 倍の差）が、接触を除いて消える |
| 損失 | 標準化後の MSE を基本とする（Huber・二重損失は使わない） | 同上。必要が出たら学習フェーズで再検討 |

q のオイラー更新による打ち切り誤差は 0.5·Δt²·ddq ≤ 1.1e-6 rad（6e-5°）で、主ゲートの 0.1° に対して無視できる。

## 4. 評価ゲート（暫定）

主ゲート (c) は決定済み。(a)(b)(d) の暫定値は、**8 kHz の接触なしデータで解析モデルの 1 ステップ RMSE を測ったあとに再設定する**（フォーク元の 0.481 rad/s² は 1 kHz のもの）。

| ゲート | 暫定しきい値 | 根拠 |
|---|---|---|
| (c) PTP 閉ループ（主） | **12 本とも発散せず、θ RMSE ≤ 0.1°**（決定） | |
| (a) 1 ステップ ddq RMSE | 純 NN (A): 解析モデルの **1.0 倍以内**。残差型 (B): **0.5 倍以内** | 1 kHz の接触なし純 MLP が 0.301 / 0.481 = 0.63 倍。(B) は解析モデルを土台にするので、より厳しく置く |
| (b) 1 秒窓の開ループ θ RMSE（8,000 ステップ） | (A) **1.0° 以下**、(B) **0.3° 以下** | 1 kHz の純 MLP 0.847°、解析モデル 0.231° |
| (d) 推論時間 | 1 ステップの中央値 ≤ 62.5 µs（周期の 50%）、99.9 パーセンタイル ≤ 125 µs | 対象ハードウェアは未決。この PC の CPU・バッチ 1 で測る |

## 5. 検証・再現確認

- 生成後に `validateJ2Data` を 8 kHz 用に拡張して、次を確認する: NaN なし、|τ| ≤ 860.4 N·m、|dq| の上限、**全サンプルがリミットから 0.1° を超えて内側**、遷移数の合計
- 同じシード・同じ条件のシナリオが、フォーク元の 8 kHz キャッシュと一致するか（single に丸めた値で比較）
- `j2Downsample(raw, 8000, 8000)` は使わない（間引き率 1 の経路は未検証で、8 kHz 版では不要）。遷移は 8 kHz の生データから直接組み立てる

## 7. 確認事項（2026-10-22 承認済み）

1. `nearlimit` は外す
2. トルク入力は瞬時値 τ(t_k)
3. 8 kHz 生データは double で保存
4. 規模はフォーク元の接触なし分そのまま（`nearlimit` を除いて 19.4 M、生成約 4 時間）
