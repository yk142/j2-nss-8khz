## 3. 検証基準の変更（リンク角速度）

当初の基準「リンク |dq| < `qdMax`」は 328 本中 16 本で超過した（最大 6.19 rad/s、`qdMax` の 118%）。16 本はすべてトルクステップ（`step_*`）で、剛体版の最大は 4.38 rad/s だった。

励振バリアはモータ角速度を制御するため、モータが減速している間に弾性でリンク側が追い越すと、リンク速度は上限を超えうる。接触でもデータの破綻でもないので、**ユーザー判断（2026-10-24）で採用**し、基準を次のとおり改めた。

- モータ側: |dqm| < `qdMax`（バリアの制御対象）
- リンク側: |dq| < 1.3·`qdMax`

学習の入力範囲は、リンク速度で `dq/5.236` の絶対値が最大 1.18 になる。NSS の評価（C4 など）では、これを超える速度は学習範囲外になる点に注意する。
