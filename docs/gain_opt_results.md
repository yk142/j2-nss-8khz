# NSS によるゲイン最適化（C4）と真値での検証 — issue #39

作成: 2026-10-26 / 要件: `docs/requirements_gain_opt.md`、計画: `docs/plan_gain_opt.md`

## 1. 実施内容

- **NSS で走査**: wn = 15·1.1^i（i = 0〜31、15〜288 rad/s）× ζ = 0.5〜2.0（0.1 刻み）の 512 ゲインで C4（1 kHz・1 ms 遅れの PD、PTP 6 本）の J を評価。モデルは B 幅 64（3 シード）、A 幅 64（3 シード）、解析モデル、負の対照（解析モデルの k ×0.9）。
- **余裕あり**の最適: (wn, ζ) と、wn ±10%（格子の隣）の 3 点がすべて安定。
- **真値で検証**: NSS の最適点とその ±10%、負の対照の最適点、境界の前後など 14 点を Simscape で評価し、既存の 21 点（#25）と合わせて 35 点。

## 2. 結果

### 2.1 NSS の最適点と真値

| モデル | 最適（余裕あり） | J（NSS） | J（真値） | 相対誤差 | 真値で安定 | 後悔 |
|---|---|---|---|---|---|---|
| B 幅 64 s0 / s1 / s2 | **(262, 0.5)** | 0.138 / 0.136 / 0.139 | 0.140 | 1.2 / 2.9 / 0.9% | ○ | 0% |
| A 幅 64 s0 / s1 / s2 | **(262, 0.5)** | 0.149 / 0.134 / 0.143 | 0.140 | 6.6 / 4.0 / 1.9% | ○ | 0% |
| 解析モデル | (262, 0.5) | 0.129 | 0.140 | 7.8% | ○ | 0% |
| 負の対照（k ×0.9） | **(63, 0.6)** | 0.498 | 0.568 | 12.4% | ○ | **305%** |

余裕なしの最適も、すべて同じ点だった。

### 2.2 合格基準（要件 §5）

| # | 基準 | 結果 |
|---|---|---|
| 1 | NSS の最適点が真値でも安定 | **合格**。B・A の 6 本すべて安定（整定ねじり 4.3e-7 rad、しきい値 3e-5 の 1/70） |
| 2 | 後悔 ≤ 10% | **合格**。0%（NSS の最適点が、真値で評価した 35 点の中の最良。次点は (238, 0.5) の 0.141） |
| 3 | 最適点での J の相対誤差 ≤ 15% | **合格**。B は 0.9〜2.9%、A は 1.9〜6.6% |
| 4 | 安定境界の位置が 10% 以内 | **合格**（ζ = 0.7・1.0・1.5 のすべて）。ただし B は、ζ = 0.7 と 1.5 で**格子 1 点分（10%）楽観的**（§3） |
| 5 | シード間の最適 wn のばらつき ≤ 10% | **合格**。B・A とも 3 シードの最適が同一 |
| 対照 | 誤差のあるモデルで悪いゲインを選ぶ | **確認**。k ×0.9 は (63, 0.6) を選び、真値の J は最良の 4.1 倍（後悔 305%）。境界の位置は対照でも 10% 以内で、基準 4 は対照を弾けない |

## 3. 読み取り

1. **NSS で選んだゲインは、真値でも最良級だった。** 最適点 (262, 0.5) の真値の J は 0.140 で、評価した 35 点の最小。NSS の J との差は 1〜7%。
2. **A と B の最適点は同じ。** 最適化の用途では、この範囲では A・B・解析モデルに差が出なかった。違いは J の絶対値（A の方が相対誤差がやや大きい）に出ている。
3. **負の対照で、検証が判別力を持つことを確認した。** 剛性を 10% 誤ったモデルは、最適を別の場所（wn 63）に選び、真値で 4 倍悪い。基準 2（後悔）と基準 3 が誤りを検出し、基準 4（境界の位置）は検出しない。
4. **B は安定境界を 1 格子分（10%）楽観的に見る。** ζ = 0.7 で NSS は wn 238 を安定とするが、真値は不安定（整定ねじり 1.4e-4）。ζ = 1.5 で NSS は wn 122 を安定とするが、真値は不安定（1.0e-4）。A と解析モデルは ζ = 1.5 で一致。**余裕の制約（±10%）が、この楽観を吸収している**。余裕なしの最適は、境界の隣ではなく ζ の下限の隅にあり、結果が同じだった。
5. **最適点は探索範囲の隅（ζ の下限 0.5）にある。** ζ < 0.5 に広げると、より良い点がある可能性が高い（J は ζ を下げるほど単調に下がっている）。後悔 0% は「評価した 35 点の中で最良」という意味で、範囲外の点との比較ではない。
6. **最適点の +10% 隣 (288, 0.5) は、真値の整定ねじりが 2.0e-5 とぎりぎり**（しきい値 3e-5）。余裕の制約は通ったが、その外側（wn > 288）は未評価。

## 4. 限界

- 真値の比較は、評価した 35 点の中での最良との比較。真値の最適そのものは、範囲の隅であることもあり未確定。
- 条件は C4 の 1 つ（遅れ 1 ms、共振 20 Hz、PTP 6 本）。遅れや共振周波数が変わった場合は未評価。
- 安定判定のしきい値 3e-5 rad は #25 の分布から決めたもの。境界の近く（整定ねじりが 1e-5 前後）では判定が揺れる。
- 学習済みモデルはスクリーニングでなく本学習（20 エポック、3 シード）だが、評価したのは幅 64 のみ。

## 5. 次の候補

- 探索範囲を ζ < 0.5（例: 0.2〜0.5）、wn > 288 に広げ、真値の最適を確かめる
- 余裕の定義を、wn のずれ以外（遅れの大きさ、k のずれ）に広げる（ロバスト最適化）
- 要件（`docs/requirements_nss_flex.md`）のゲート (a) を参考値に下げる更新
