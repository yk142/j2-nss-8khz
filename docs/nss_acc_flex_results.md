# 弾性 J2 への加速度状態 NSS の拡張 — issue #51

作成: 2026-10-29 / 要件: `docs/requirements_nss_acc_flex.md`

## 1. 実施内容

弾性 2 慣性の NSS(状態は直前区間の加速度 (ddθ, ddθm))を作り、B(残差型)・A(純 NN)と比べた。幅 64、20 エポック。

- F0: ノイズなし(シード 0)
- F1: 入力 acc にガウスノイズ。σ = r × Δacc の列ごとの標準偏差。r = 2.5, 5, 10(シード 0)。r = 2.5 と 5 は 3 シード
- (c3): C4 の 21 ゲイン判定一致 + Spearman J
- ゲイン最適化: #41 と同じ格子(820 ゲイン)を走査し、#39/#41 の真値 40 点で検証

F2(ロールアウト損失 K=16 の併用)は行っていない(§4)。

## 4. 読み取り

1. **ノイズなしは自己回帰で破綻する。** F0 は (a) が最良(0.049)だが、(b) 2.5°、(c) 1.8° で不合格。剛体 (#45) と同じ。
2. **入力 acc のノイズ(r=2.5〜10)で、全ゲート・(c3)・ゲイン最適化に合格した。** r の違いに有意な差は見えない。ノイズを入れると 1 ステップの (a) は悪化する(0.049 → 0.2〜0.34)が、閉ループには効かない。
3. **精度の序列:** (c) 閉ループは acc が B・A の約 1/2.5、(b) θ は B(0.020)が最良で acc と A が同程度、(b) ねじりは acc が 0.09 倍で最良、(c3) の Spearman は B(0.997)≥ acc ≈ A。
4. **スループットは acc が最速**(約 790k、B の 1.5 倍、A の 1.3 倍)。
5. **ゲイン最適化では B・A・解析モデルと同等。** 余裕あり最適のシード間の揺れ(238 / 262)は、B・A(3 シードとも 262)よりやや大きい。J の絶対値の誤差は B と同程度。
6. **判定:** 「acc 状態が有利」とまでは言えないが、**B 並みの用途性能が、物理モデル(解析モデルの加速度)なしの純 NN で得られた。** A(純 NN)に対しては、(b) ねじり、(c)、スループットで上回る。物理の先験知識を使える間は B が精度で優位。

## 5. 限界

- F0 と r=10 は 1 シード。r=2.5 と 5 の差(ばらつき内)は判別できない。
- F2(ロールアウト損失の併用)は未実施。剛体では (c) のみ改善し学習時間は約 3 倍だった。ここでは (c) がすでに基準の 1/30 で、必要性が低いと判断した。
- 学習は幅 64 のみ。幅や深さの感度は未評価。
- C4 の 1 条件(遅れ 1 ms、共振 20 Hz)のみ。
