# 加速度状態 NSS のロールアウト損失との比較 — issue #49

作成: 2026-10-28 / 要件: `docs/requirements_nss_rollout_loss.md`

## 1. 実施内容

窓長 K の自己回帰（窓の先頭の acc は真値）の損失を、1 ステップ損失に加えた。**案 1（teacher）**は pos/vel を各ステップで真値にして acc だけを自己回帰、**案 2（full）**は acc から積分した pos/vel も自己回帰（トルクは真値）で、真値からのずれ（dq, q）も損失に入れる。窓の数は K = 4 で 256、K = 16 で 128。幅 64、seed 0、20 エポック。実装は `train_nss_acc.py --rollout-k/--rollout-mode/--rollout-batch`、`tools/run_acc_rollout.sh`。

## 3. 読み取り

1. K = 4 は効かない（A、D は基本形と同じ）。K = 16 で大きく改善する（B、C）。
2. 案 2 は案 1 より (c) が良い（0.113° → 0.046°）が、学習が約 25% 長い。
3. ロールアウト損失の単独は、ノイズ学習（σ = 1.0）を上回らず、学習時間は約 3 倍。
4. 併用（E1、E2）は全ゲートに合格し、(c) は σ = 1.0 単独より良い（0.032° → 0.018〜0.020°、B 幅 64 の 0.022° と同等）。(b) は 0.185〜0.187° で、σ = 1.0 単独（0.206〜0.238°）との差はシード間のばらつきの内。
5. 案 1 と案 2 の併用に大きな差はなく、案 1 の方が安価（学習時間が約 2.9 倍に対し約 3.5 倍）。
6. **案 1 の併用は 3 シードとも全合格。** (b) の平均は 0.217° で σ = 1.0 単独（0.223°）と差がない。(c) の最悪は平均 0.021° で単独（0.033°）より約 4 割低く B 幅 64（0.022°）と同等だが、シード 1（0.031°）は単独とほぼ同じで、改善は小さい。学習時間は約 3 倍。
7. ゲートを満たすだけならノイズ学習で十分。(c) の最悪値を下げたいときに限って、併用が選べる。

## 4. 限界

- 併用の 3 シードは案 1 のみ。案 2 の併用は seed 0 のみ。
- K は 4 と 16 のみ。窓の数・重みは調整していない。
- 剛体のみ。弾性（4 自由度）は未評価。
- 学習時間はノイズ学習（16 分）比。最良エポックは 1 ステップ + ロールアウトの検証損失で選んだ。
