# ゲイン最適化の探索範囲の拡張と、真値での最適の確認 — issue #41

作成: 2026-10-26 / 前提: `docs/gain_opt_results.md`（#39）

## 1. 実施内容

- 範囲を ζ = 0.1〜2.0（0.1 刻み）、wn = 15〜680 rad/s（1.1 倍刻み、41 点）の 820 ゲインに拡張（#39 の 512 点は再利用、新規 308 点）。
- 解析モデル、B 幅 64（3 シード）、A 幅 64（3 シード）、負の対照（k ×0.9）で NSS の J を走査。
- 余裕の制約（wn ±10% も安定）は #39 と同じ。
- 新しい最適点の周辺と、ζ の下側の 5 点を真値（Simscape）で評価。#39 の 35 点と合わせて 40 点。

## 2. 結果

### 2.1 NSS の最適点は範囲の内側にある

- B・A の 6 本すべてで余裕あり最適は **(262, 0.5)** のまま（範囲の隅ではない）。解析モデルは (262, 0.4)。
- J は ζ = 0.4〜0.5 でほぼ平ら（B s0: 0.139〜0.138）。ζ = 0.3 で 0.146、0.2 で 0.192、0.1 で 0.89 と悪化。
- 安定領域は wn が大きいほど ζ の範囲が狭く、ζ = 0.5 では wn 288 付近まで。wn > 288 は不安定。
- 負の対照（k ×0.9）は #39 と同じ (63, 0.6)。

### 2.2 真値

| ゲイン (wn, ζ) | 真値 J | 整定ねじり | 安定 |
|---|---|---|---|
| (262, 0.5) | 0.1400（最良） | <1e-6 | ○ |
| (288, 0.4) | 0.1407 | <1e-6 | ○ |
| (238, 0.5) | 0.1414 | <1e-6 | ○ |
| (262, 0.4) | 0.1422 | <1e-6 | ○ |
| (262, 0.3) | 0.1539 | 8.5e-7 | ○ |
| (197, 0.2) | 0.1911 | 8.4e-7 | ○ |

真値でも ζ を 0.5 より下げると J は悪化する。真値の最良は (262, 0.5) で、40 点の中で変わらなかった。

### 2.3 判定

| 基準 | 結果 |
|---|---|
| 1 安定 | B・A 6 本とも合格 |
| 2 後悔 ≤ 10% | B・A とも 0%。余裕なし最適は最大 0.5%。解析モデル 1.5% |
| 3 J の相対誤差 ≤ 15% | B 0.9〜2.9%、A 1.9〜6.6%、解析モデル 9.4% |
| 5 シード間 | 最適 wn が 3 シードとも同一 |
| 対照（k ×0.9） | (63, 0.6) を選び、後悔 305% |

## 3. 読み取り

1. #39 の「最適点が隅にある」という懸念は解消した。ζ < 0.5、wn > 288 まで広げても、NSS・真値とも最適は (262, 0.5) 付近。
2. 最適点付近は平らで、(288, 0.4) など隣の点との真値の差は 1% 以内。「どれを選んでも同等」の領域がある。
3. wn 288 の側は安定境界に近く、余裕の制約が効いている。

## 4. 限界

- C4 の 1 条件（遅れ 1 ms、共振 20 Hz、PTP 6 本）のみ。遅れや k のずれに対するロバスト性は未評価。
- 格子は wn 10%、ζ 0.1 刻み。最適点付近の細かい最適化はしていない。
