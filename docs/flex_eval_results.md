## 2. 解釈

- **合格基準 1（内部最適）は満たさない。** 条件ごとのコスト J（追従と整定ねじりを (30, 1) の値で正規化して平均）の最小は、C0 が (120, 1)、C1 が (120, 1.5)、C3 が (120, 0.7) と、いずれも格子の高ゲイン端。4 条件の J の合計の最小も (120, 1)。
- **C2 だけは向きが逆。** 追従は wn を上げるほど悪化し（0.095 → 0.109）、J の最小は (15, 1.5)。FF が想定する剛性が外れると、ゲインを上げても追従が良くならない。ただし最適が低ゲイン端で、これも内部ではない。
- **振動はそもそも小さい。** 整定ねじりは最大でも 6e-5 rad。衝撃外乱（100 N·m × 2 ms）も 0.05〜0.09 s で減衰し、ゲイン差は小さい。モータ側 PD（コロケーション）は、wn=120（約 19 Hz、共振 20 Hz の近く）でも共振を十分に減衰する。
- したがって合格基準 3 に該当する: **PTP＋モータ角 PD では、制振性能でゲインの順位はつかない。** 順位を決めるのは追従で、剛性ずれ（C2）のときだけ高ゲインが不利になる。

## 3. 限界と次への示唆

- 指標は追従と、静止区間のねじりだけ。軌道の最中の揺れ（動的ねじり）は C2・C3 では参照との差で測っていない。
- ゲイン範囲は wn ≦ 120。さらに高ゲインや、モータ速度へのノイズ・遅れを入れると、高ゲインで不利になる可能性がある（実機に近い条件）。
- 制振が主題なら、リンク側の振動を直接見る評価（先端加速度など）や、サンプル遅れ・ノイズ付きのフィードバックが候補。

## 4. 追加条件 C4（1 kHz サンプル・ホールド＋1 ms 遅れ）の結果

- **持続振動（リミットサイクル）**: wn=180 の ζ=1・1.5 と wn=240 の 3 組で、トルク RMS が 100 N·m 台から 560〜760 N·m に跳ね上がり、整定ねじりが 1e-6 rad 台から 3e-4 rad に増えた。wn=180, ζ=0.7 だけは安定。ζ が小さいほど高ゲインまで安定。
- **内部最適**: J（追従と整定ねじりを (30,1) で正規化して平均）は ζ=1 で wn=90（0.18）、ζ=1.5 で wn=60（0.36）が内部最小。全体の最小は (180, 0.7)（0.16）で、不安定領域に隣接する端。動的ねじりを使った J でも同じ点。
- **解釈**: 遅れを入れると高ゲインの不安定化が現れ、ゲインを選ぶ意味が出る（理想的な連続フィードバックでは見えなかった）。劣化の始まる wn=120〜180（約 20〜30 Hz）は共振 20 Hz の近くだが、共振によるのか遅れによる位相余裕の不足なのかは切り分けていない（剛体プラントに同じ遅れを入れて比べれば分かる）。
