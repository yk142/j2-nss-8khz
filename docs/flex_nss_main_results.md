## 3. 読み取り

1. **12 本すべて、(a)〜(d) と (c3) に合格した。** スクリーニング（5 エポック）で (a) が不合格だった A も、20 エポックで 0.3〜0.9 倍になり合格した。
2. **A はシード間のばらつきが大きい**（(a) ddq 比 0.30〜0.87）。B は 0.02〜0.03 でほぼ一定。
3. **ねじりの精度（(b)）は A・B とも解析モデルの約 0.5 倍**で、#34 の目安（2 倍以内）の内側。(c3) の順位は B が 0.997 で解析モデルと同等、A はそれよりわずかに低い。
4. **幅 64 と 128 に精度の差はほぼない**（(b) θ は A で 0.042 と 0.037、B で 0.020 と 0.021）。スループットは幅 64 の方が約 1.8 倍速い。
5. **(c) 最悪は 0.006° 前後で、基準 0.1° の約 1/17。** A・B・幅の違いによる差はほぼ見えない。#34 のとおり (c) は弱いゲートで、差は (b) と (c3) に出る。

## 4. 採用案

- **B（残差型）幅 64** を第一候補とする。(b) θ が A の約半分で、シード間のばらつきが小さく、スループットは幅 128 の約 1.8 倍。
- A 幅 64 も全ゲートに合格しており、純 NN で足りる可能性を残す。ただし (a) のばらつきが大きいので、採用するならシードを増やして確認する。
- ゲート (a) の「解析モデルの 1.0 倍」は、本学習ではすべて合格した。#34 で提案した「(a) は参考値、合否は (b) ねじりと (c3)」への変更は、本学習の結果からは必須でなくなったが、判定の考え方としては維持する。

## 5. 限界

- (c3) は C4 の 21 ゲイン・PTP 6 本の範囲。他の遅れや共振周波数のずれは未評価。
- 学習データは遅れ付き PD を含まない（要件の決定）。C4 の再現は、二慣性の物理が支配的なためとみられる（解析モデルだけでも合格）。
- ddqm の 0.82〜0.86 倍は、真値が区間内の平均トルクで進むことによる下限（#33）。
- 時系列プロットは `reports/issue-37/plots/`。
