# 要件定義（ドラフト）— 加速度を状態に持つ残差型 NSS（acc₁ = acc + NN([acc; u])）

作成: 2026-10-26 / 更新: 2026-10-26（別プロジェクトの回答を反映）/ issue #45 / 状態: **§7 の 1〜3 を決定。実装に進む**

## 1. 目的

別プロジェクトで検討中の NSS アーキテクチャを、このプロジェクトのデータとゲート (a)〜(d) で試し、現行（B 幅 64、A 幅 256）と同様の結果が得られるかを見る。

- 第 1 段: **ねじり弾性なし（剛体 J2 単軸）**。データは `data/export/j2_nss8k.h5`（train 13.2 M 遷移）
- 第 2 段: 4 自由度（弾性、`j2_nss8kflex.h5`）への拡張。第 1 段の結果を見てから別 issue にする

## 2. アーキテクチャ（別プロジェクトの回答、2026-10-26）

| 変数 | 次元 | 内容 |
|---|---|---|
| 状態 x | 1 | `acc`（モータ加速度） |
| 入力 u | 3 | `[trq, pos, vel]` |

- 状態方程式: `x₁ = x + NN([x; u])`。NN の入力は `[acc, trq, pos, vel]`（4 次元）、出力は `Δacc`（1 次元）、次状態は `acc_{k+1} = acc_k + Δacc`（残差接続）
- `pos`, `vel` は 1 ステップ学習時には真値（教師強制）から取る
- ロールアウト（閉ループ）時の `pos`/`vel` の扱い（積分スキームなど）は別途決定
- アブレーション（別実験で比較）: (i) `τ_{k-1}` を状態に含める拡張、(ii) `Δpos`・`Δvel` を NN に学習させる拡張

## 3. 本プロジェクトでの具体化（案）

剛体では「モータ加速度」は関節加速度 ddq と同じ。時刻 k のデータ（`X_raw` = q, dq, τ は区間先頭の瞬時値）に対して:

- `acc_k = ddq_{k-1} = (dq_k − dq_{k-1}) / Δt`（直前の区間の加速度。現行データの `Y[k-1]`）
- 入力 `u_k = [τ_k, q_k, dq_k]`
- 目標 `acc_{k+1} = ddq_k = Y[k]`（現行の目標と同じ）。NN の学習目標は `Δacc = Y[k] − Y[k-1]`
- 同じシナリオ内の連続する遷移をつないで `acc_k` を作る。各シナリオの最初の遷移（k = 0）は前の値がないので除く（0.01% 未満）。データの再生成は不要
- ロールアウト時の `pos`/`vel` の積分（別プロジェクトの回答）: 加速度→速度は前進オイラー `dq_{k+1} = dq_k + Δt·acc_{k+1}`、速度→位置は台形則 `q_{k+1} = q_k + Δt/2·(dq_k + dq_{k+1})`。現行は位置も前進オイラー（`q + Δt·dq`）で、ここが違う

## 4. 現行（`python/nss8k`）との違い

| 観点 | 現行 | 回答のアーキテクチャ |
|---|---|---|
| NN の入力 | `sin q, cos q, dq, τ`（4 列。B は + `a_phys` で 5 列） | `acc, τ, q, dq`（4 列。前の加速度が入る） |
| NN の出力 | `ddq`（B は解析モデルに足す残差） | `Δacc`（前の加速度に足す残差） |
| 状態 | (q, dq) | (acc)。q, dq は入力側で、積分は別 |
| 残差の基準 | 解析モデルの加速度（B）、なし（A） | 前の加速度（恒等写像が出発点） |
| 記憶 | なし（q, dq から毎回計算） | 前の 1 ステップの加速度 |
| 物理の先験知識 | 重力・慣性・摩擦（B） | なし（純 NN） |
| q, dq の更新 | 両方とも前進オイラー | 速度は前進オイラー、位置は台形則 |

本質的な違いは **「前の加速度を入力に使う」ことと「出力が加速度の差分になる」** の 2 点だけ。積分の違いは位置の台形則だけで、現行の A（純 NN）に「前の加速度の入力」と「差分の出力」を足した形になる。

予想される点（検証すること）:

1. 加速度は 125 µs で連続的に変わる（トルクの変化が主因）ので、前の加速度は次の加速度の強い予測子。1 ステップ予測（(a)）は A より良くなると予想
2. ただし**閉ループ・自己回帰では、前の加速度の誤差が次に入る**。誤差が減衰するか、積み上がるか。θ = 0 まわりの不安定性（成長率 約 3.5/s）との相互作用が (b)(c) で試される
3. 学習時は前の加速度が真値、ロールアウト時はモデル自身の出力になる（教師強制と自己回帰の差）。(a) と (b) の差に出る見込み

## 5. 実装の方針（案）

- 入力特徴: `acc_k / s_a`, `τ_k / 860.4`, `q`（生の位置）, `dq / 5.236` の 4 次元。train の平均・標準偏差で標準化
- 出力: `Δacc` を train の標準偏差で割って学習。最後の層は 0 初期化（恒等写像から開始）
- 損失: 標準化後の `Δacc` の MSE。まず 1 ステップ損失のみ。(b)(c) が悪ければ、複数ステップ（自己回帰）の損失を検討する
- ネットワーク: 3 層 SiLU、幅 64 と 256（A 幅 256 と同じ幅も試す）。学習は現行と同じ設定（Adam、20 エポック、早期終了 patience 5、3 シード）。まずスクリーニング（5 エポック、1 シード）
- アブレーション: 回答の (i) `τ_{k-1}` を状態に追加、(ii) `Δpos`・`Δvel` を NN に学習させる。基本形の結果を見てから行う

## 6. 評価ゲート

現行の剛体版（`docs/main_training_8khz.md`）と同じ。

| ゲート | しきい値 | 現行（比較対象） |
|---|---|---|
| (a) 1 ステップ ddq RMSE（test） | 解析モデルの 1.0 倍以内（参考値だが比較のため測る） | B w64: 0.49 倍、A w256: 0.55 倍 |
| (b) 4,000 ステップ窓の開ループ θ RMSE | ≤ 0.4° | B: 0.12°、A: 0.31° |
| (c) PTP 閉ループ（12 本） | 発散せず θ RMSE ≤ 0.1° | B: 0.022°、A: 0.033° |
| (d) スループット | ≥ 145,000 ステップ/s | B w64: 約 744k、A w256: 約 162k |

加えて記録するもの: (a) と (b) の差（教師強制と自己回帰の差）、加速度の誤差の閉ループでの挙動。

「同様の結果」の判定: 4 ゲートすべて合格なら使える。現行の A と同等以上なら「純 NN として同等」、B に並べば「物理を使わずに B 相当」と報告する。

## 7. 確認してほしいこと

1. **pos の入力の形**: 決定（2026-10-26）。回答どおり生の q で基本形を作り、`sin q, cos q` はアブレーションにする
2. **`acc` の定義**: 決定（2026-10-26）。時刻 k の状態は直前の区間の加速度 `(dq_k − dq_{k-1})/Δt`（現行データの `Y[k-1]`）。次の状態は `Y[k]`
3. **ロールアウトの積分**: 決定（2026-10-26、別プロジェクトの回答）。速度は前進オイラー、位置は台形則
