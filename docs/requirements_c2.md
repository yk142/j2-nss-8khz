# 要件— ゲイン違いの再現性 (c2)

作成: 2026-10-24 / issue #19 / 状態: **確定（2026-10-24、ユーザー承認）**。§3 の案の値（外乱 20 N·m・0.5 s、FF 誤差 ±15%、整定 0.05°、J の重み 1 : 1、合否のしきい値）をそのまま採用。

## 1. 目的

NSS（8 kHz）をオフラインのゲイン最適化に使えるかを確かめる。PD ゲイン（wn, ζ）を変えたときの閉ループ応答とコストの**順位**が、Simscape の真値と合うかを評価する（`docs/training_8khz.md` §7 の項目 2）。モデルの再学習はしない。評価するのは採用済みの 2 本（`models/nss8k/B_w64_s2`、`A_w256_s2`）。

## 2. 前提（実測）

- 既存の真値（wn = 30、ζ = 1、FF 正確、外乱なし）の PTP 追従誤差は 0.0003〜0.006° しかない（`reports/issue-16` の `truth_track_rmse_deg`）。FF が正確なので、ゲインを変えても応答にほとんど差が出ない。**このままでは順位がノイズで決まり、評価にならない**。
- そこで、ゲインの違いが応答に出る条件として、**FF の係数誤差と外乱トルクを加えた真値**を新しく作る（ユーザー決定）。
- `buildJ2ClosedLoop` は wn, ζ を引数に取り、入力 `[q_ref, dq_ref, tau_ff, tau_dist]` を持つ。ゲインの変更、FF の誤差、外乱は、プラントの作り直しなしにできる。

## 3. 評価の設計（案）

### 3.1 ゲインの組（ユーザー決定: 3×3 = 9 組）

wn ∈ {15, 30, 60} rad/s × ζ ∈ {0.7, 1, 1.5}。Kp = M·wn²、Kd = 2·ζ·M·wn（現行と同じ）。

### 3.2 条件（ユーザー決定: FF 誤差と外乱の両方）

軌道は `benchmark` の PTP 12 本（`ptp_v20/40/60/80 × 3`、1 本 2.6〜14 s、計約 62 s）。各ゲインの組に、次の 2 条件を当てる。

| 条件 | FF の係数（M, mgL, Bv, Fc） | 外乱 tau_dist |
|---|---|---|
| E1 | すべて **−15%** | **+20 N·m**（0.5 s のパルス。軌道ごとに開始時刻を決める） |
| E2 | すべて **+15%** | **−20 N·m**（同上） |

- 外乱の 20 N·m は、重力トルクの最大 73 N·m の約 3 割、トルク上限 860 N·m の約 2%（案）。パルスの開始時刻は軌道のシードから決め、モデルと真値で同じにする。
- FF の誤差は FF だけに入れる。プラント（真値）の係数は変えない。
- 既存の「FF 正確・外乱なし」の条件は、ゲインを振らない (c) として別に判定済み。

### 3.3 真値の生成

- 9 組 × 2 条件 × 12 軌道 = 216 本。Simscape 8 kHz（実時間の 5.5 倍）で、1 組・1 条件あたり約 6 分、合計約 1.8 時間（案）。
- 出力: `data/c2/` に MATLAB の .mat（git 管理外）。生成は `tools/j2_gen_c2.m`（案）。シナリオ単位でキャッシュし、中断しても再開できる。

### 3.4 NSS 側の評価

- Python の閉ループ（`closed_loop_batch`）を、ゲイン・FF の誤差・外乱を引数に取る形に拡張する。条件ごとに全軌道を同時に進める。
- 評価するモデル: B w64 seed 2、A w256 seed 2（解析モデルを参考に併記）。

### 3.5 指標とコスト

各（ゲインの組、条件）で、12 軌道の平均として次を真値・NSS の両方で求める。

| 指標 | 内容 |
|---|---|
| θ RMSE | 参照軌道との追従誤差 [°] |
| τ RMS | 印加トルクの RMS [N·m]（エネルギーの目安） |
| 最大誤差 | \|θ − θ_ref\| の最大 [°] |
| 整定時間 | 各到達点で、誤差が 0.05° 以内に入るまでの時間 [s] の平均 |

ゲイン最適化の目的関数として、**コスト J = θ RMSE / (真値の中央値) + τ RMS / (真値の中央値)**（各項を、同じ条件の 9 組の真値の中央値で割って無次元化）を使う（案）。

### 3.6 合否（ユーザー決定: 順位相関＋最適ゲインの一致）

条件 E1・E2 それぞれで、9 組の J の順位について、次を**両方**満たすこと。

- 真値と NSS の J の順位相関（Spearman）≥ **0.9**
- NSS で J が最小となる組の、真値での J が、真値の最小値の **5% 以内**

加えて報告（合否に使わない）: 各組の θ RMSE の真値との差、最大誤差と整定時間の順位相関、発散の有無。

## 4. スコープ外

制振（弾性プラント）、モデルの再学習、ゲイン以外の制御器（積分・外乱オブザーバなど）。

## 5. 実装の計画

1. **真値の生成（MATLAB）**: `src/data/runJ2PtpC2.m`（参照軌道は `runJ2Scenario` の ptp と同一。FF の係数を (1 + ffErr) 倍、外乱パルスの開始時刻は軌道のシード + 7 から決める）と、`tools/j2_gen_c2.m`（9 組 × E1/E2 × 12 軌道、2 ワーカーに分割、キャッシュ付き）。出力は入力（qref, dqref, tauFf, tauD）も保存し、Python の閉ループにそのまま使う。
2. **検証**: 条件 N（wn = 30、ζ = 1、FF 正確、外乱なし）を生成し、既存の benchmark のキャッシュと一致することを確かめる（生成コードの正しさの確認）。
3. **NSS 側（Python）**: `closed_loop_batch` に、ゲイン・保存済みの入力（FF、外乱）を与える形を追加（既存の呼び出しは変えない）。`python/evaluate_c2.py` で、2 モデル（と解析モデル）× 9 組 × E1/E2 の閉ループを実行し、§3.5 の指標・J・順位相関・最適ゲインの一致を `reports/issue-19/` に出す。
4. **単体テスト**: ゲイン付き閉ループが従来の (30, 1) と一致する、指標の計算、Spearman。
5. 結果を `docs/c2_results.md` にまとめる。

## 6. 確定した設定の補足

- 外乱パルス: 矩形、20 N·m（E1 は +、E2 は −）、0.5 s、開始時刻 = 軌道のシード + 7 から決める乱数 × (軌道長 − 0.5 s)。PD の出力と FF に足してから ±τ_peak で飽和（Simulink の構成と同じ）。
- 真値のゲインは Kp = M·wn²、Kd = 2·ζ·M·wn。FF の誤差は、FF の 4 係数（M, mgL, Bv, Fc）すべてを同じ倍率で変える。
