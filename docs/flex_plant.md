# 弾性（二慣性）J2 プラントの実装と検証 — issue #21

2026-10-24。要件は `docs/requirements_flex.md`。減速機のねじり弾性を入れた J2 単軸の真値プラントを作り、物理を検証した。

## 使い方

```matlab
addpath('config'); addpath(genpath('src'));
[mdl, flex] = buildJ2FlexPlant();                  % data/models/j2_flex_plant.slx（約 10 s）。既定: 共振 20 Hz、減衰比 0.05
% 'fRes'（共振周波数 Hz）、'zetaTors'（減衰比）、'kScale','cScale'（k, c の倍率）、'noFriction'（摩擦 0、検証用）
setJ2InitialState(mdl, q0, dq0, twist0);          % 第 4 引数は初期ねじり角 θm − θ [rad]（既定 0）
% 入出力: Inport 'tau'（モータ側へ入るトルク）、Outport 1 q、2 dq（リンク）、3 tauOut（素通し）、4 qm、5 dqm（モータ側）
results = runtests('test/test_j2_flex_plant.m');   % 検証 6 件（約 4 分）
```

`runJ2Sim` は 1〜3 番目の出力を読むので、弾性プラントでも `out.q/dq/tau` は使える（`qm`/`dqm` は読まない。4・5 番目を直接読む）。

## モデル

| 項目 | 値 |
|---|---|
| Jm（モータ側） | 2.2896 kg·m²（親資産の armature） |
| JL（リンク側） | 3.7961 kg·m²（= M − Jm。M = 6.0857） |
| k | 22,553 N·m/rad（共振 20 Hz） |
| c | 17.95 N·m·s/rad（ねじりモードの減衰比 0.05） |
| 摩擦・重力 | リンク側（現行のまま） |

実装: `src/plant/addJ2Flex.m`（`buildJ2Plant` の `opts.flex` から呼ばれる。剛体の `addC8Armature` の代わり）、`src/plant/buildJ2FlexPlant.m`。既定の剛体プラント（`buildJ2Plant`）の挙動は変えていない（既存の `test_j2_plant` 13 件が合格）。

**実装上の注意（実測で判明）**: Rotational Multibody Interface の R 端の角速度は、関節角速度と**逆符号**（実測: `wR = −dq`）。そのためモータ側の機械回転ドメインは「−θm」の座標で組み、制御トルクは PS Gain −1 を通してトルク源に入れ、`qm`・`dqm` は出力側で符号を戻している。初期状態は、ばねの初期変位（`phi`）、モータ慣性の初期角速度（`−dq0`）、センサの offset（`−(q0 + twist0)`）で与える（`setJ2InitialState`）。

| # | 検証 | 結果 | 合格基準 |
|---|---|---|---|
| 1 | 剛体極限（k×100、c×10 を剛体プラントと比較） | θ の差の最大 0.0004 rad（剛体の変化量 0.163 rad の **0.23%**） | 1% 以内 |
| 2 | 共振周波数（摩擦なし、パルス後のねじり自由振動の FFT） | **19.96 Hz** | 20 Hz の ±5% |
| 3 | 減衰比（摩擦なし、初期ねじり 0.05 rad の自由振動の包絡線） | **0.0494** | 0.05 の ±30% |

## 気づき（次の issue のために）

- **摩擦が共振を強く減衰する**: リンク側のクーロン摩擦（tanh 幅 ε = 0.013 rad/s）は、リンク速度が小さい領域で実効的に 1,800 N·m·s/rad 相当の粘性になる。小さな振動はリンク側でほぼ止まるため、共振の検証（2・3・5）は摩擦なしの別条件で行った。実運転で共振が見えるのは、リンクが十分な速度で動いているとき（摩擦が一定のトルクになる領域）に限られる。摩擦をモータ側・減速機側に分配するかは、次の issue で再検討してよい。
- **閉ループ（PD）は未対応**: `buildJ2ClosedLoop` は弾性プラントに対応していない（出力ポートの番号が衝突する）。次の issue で、弾性プラント用の閉ループを作る。
- **状態が増える**: 弾性プラントの状態は (θ, dθ, θm, dθm) の 4 つ。NSS の入力 (q, dq, τ) だけでは、モータ側の状態が隠れる。次の issue で、NSS の入出力の再検討が要る。
