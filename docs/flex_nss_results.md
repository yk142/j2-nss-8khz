## 3. 分かったこと

1. **B は幅 64・128 で全ゲートに合格。** B 幅 256 は精度は最良（ddq 0.040 倍）だが、速度が 131k で (d) を割る。幅 128（306k）が速度と精度のバランスで無難
2. **A は幅によらず (a) 不合格。** ddq が解析モデルの 4〜5 倍悪い。開ループの窓でも、step 系で θ が真値から 1° 近くずれていく（`plots/window_step.png`）。弾性版でも剛体版と同じく、純 NN は採用しない
3. **(c) は判別力が弱い。** 解析モデルだけでも最悪 0.0045° で、基準 0.1° の 1/20。モデル間の差も小さい。制振の評価ができるかは (c3)（C4 の再現）で決まる
4. **ddqm の 1 ステップ誤差には、学習で下げられない下限がある。** B でも解析モデルの 0.82 倍で止まり、幅を上げても動かない（val RMS 0.2128〜0.2154 rad/s²）。原因を調べた（§4）

## 4. ddqm の下限の原因

test の 1 ステップで、ddqm の残差（真値 − 解析、RMS 0.249 rad/s²）を、区間内の量で回帰した。

- 説明変数: 区間内のトルク変化 0.5·Δτ/Jm と、ばね力の変化 0.5·Δts/J（Δ は次の行との差）
- 係数は 1.000 と 1.000、**残差 RMS は 0.249 → 0.0028 rad/s²**
- パターン別: `step` の ddqm 残差 1.553 に対し 0.5·Δτ/Jm の RMS は 1.560（ほぼ一致）。`freefall`（トルク 0）は 0.001

つまり、真値の 1 ステップは**区間内の平均トルクで進む**のに、モデルの入力は区間先頭のトルク τ_k だけである。次のトルク τ_{k+1} を知らないと、τ の変化分は予測できない（`plots/ddqm_floor.png`）。バグでもモデルの容量不足でもなく、入力の定義による下限で、剛体版の「トルクをステップ内で保持と見なす誤差」と同じもの。

影響:

- 記録トルクを再生する 1 ステップ誤差 (a) では、解析モデルより悪くならない（0.82 倍）ので問題にならない
- 閉ループでは、トルクが滑らかなので影響は小さい（(c) のねじり差は 1.7e-05 rad）
- トルクが急変する場面（`step` の立ち上がりなど）で、ddqm が半サンプル分ずれる
