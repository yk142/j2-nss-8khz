# 加速度状態 NSS への入力ノイズ学習 — issue #46

作成: 2026-10-27 / 前提: `docs/nss_resid_state_results.md`（#45）

## 1. 実施内容

#45 の基本形（幅 64、20 エポック）は 1 ステップ精度が高い一方、自己回帰の (b)(c) が不合格だった。学習時に入力 acc へ標準偏差 σ [rad/s²] のガウスノイズを加え、目標を `y − acc_noisy` にする（ノイズ除去型）。損失は 1 ステップのみで、ロールアウト損失は使わない。検証はノイズなし。実装は `train_nss_acc.py --acc-noise`、`tools/run_acc_noise.sh`、`tools/run_acc_noise_seeds.sh`。

## 3. 読み取り

1. **σ = 1.0 は 3 シードとも (a)〜(d) 全合格。** (b) は基本形の約 1/100、シード間のばらつきも小さい。
2. σ が小さい（0.02〜0.1）と効果がなく、0.1 では (c) が悪化した。0.5 以上で急に効く。1.0 が最良、2.0 は (b) がやや悪化。
3. (a) は σ とともに悪化（0.26 → 0.50）。1 ステップ精度と引き換えに自己回帰の頑健性を得ている。
4. 現行との比較: (b) は A 幅 256（0.31°）より良く、B 幅 64（0.12°）には届かない。(c) は A 幅 256（0.033°）と同等、B 幅 64（0.022°）には届かない。
5. 検証 RMS（ノイズなし）は、ノイズ学習の効果を測れない（σ = 0.5 以上でも約 0.2〜0.24 rad/s² で、(b)(c) は大きく改善）。

## 4. 限界

- ノイズ学習は別プロジェクトの仕様にない。共有と合意が必要。
- σ は粗い 6 点のみ。0.5〜2.0 の間は最適化していない。σ ≥ 1.0 の複数シードは 1.0 だけ。
- 剛体のみ。弾性（4 自由度）は未評価。
- 最良エポックは、ノイズなしの検証損失で選んでいる。
