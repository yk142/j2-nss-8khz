# C4 の高ゲイン劣化は共振か遅れか — 要件（issue #27）

作成: 2026-10-24

## 目的
#25 の C4（PD を 1 kHz サンプル・ホールド＋1 ms 遅れ）の劣化が、共振 20 Hz によるのか、遅れによる位相余裕の不足なのかを切り分ける。

## 条件
- **C5**: C4 と同じ閉ループ（1 kHz、1 ms 遅れ、同じ FF、軌道 6 本、21 ゲイン）で、プラントの剛性を 100 倍、減衰係数を 10 倍にする（共振 約 200 Hz、ほぼ剛体）
- 比較する量: 追従 RMS、トルク RMS、持続振動（トルク RMS の跳ね上がり）が出る境界の wn

## 判定
- C5 でも C4 と同じ wn で持続振動が出る → 原因は遅れ（共振は主因でない）
- C5 では出ない、または大幅に高い wn まで出ない → 共振が絡む
- 中間（境界が移る）なら、その移動量を記録する

## 限界
- 剛性 100 倍でも厳密な剛体ではない（共振 200 Hz は 1 kHz のナイキスト 500 Hz より下）。完全な剛体の閉ループ（`buildJ2ClosedLoop`）にはサンプル・ホールドを入れていない
