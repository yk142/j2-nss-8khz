## 分かったこと

1. **(a) は benchmark（PTP）で全モデルが不合格**。PTP は滑らかで、解析モデルの誤差が 0.147 rad/s² と小さい。学習したモデルは 0.16〜0.29 で、解析モデルを超えられない（倍率 1.1〜1.9）。test では B が 0.52〜0.59 倍で、0.5 倍に近い。**benchmark で「解析モデルの 0.5 倍」は、現状では届きそうにない**。5 エポックで未収束の影響もあるが、ゲートの置き方も見直す余地がある（下記）。
2. **(c) は学習の良し悪しを区別しない**。解析モデルだけで最悪 0.0099°、学習モデルは 0.014〜0.036° で、どれも閾値 0.1° の 3 分の 1 以下。B は A より小さい（0.014〜0.020° 対 0.025〜0.036°）。
3. **(b) は B の方が良い**（B 0.36〜0.56° 対 A 0.70〜0.96°）が、B でも解析モデルの 0.245° より悪い。`rollout_horizon.png` を見ると、学習モデルは約 3,000 ステップ（0.4 秒）まで解析モデルより誤差が小さく、その後に逆転する。θ=0 まわりの不安定性（成長率 約 3.5/s）で誤差が増幅されるため、**ステップ 8,000 の 1 点で比べると、僅かなバイアスが大きく効く**。
4. **B は A より良い**（test 0.28〜0.31 対 0.32〜0.43、(b)(c) も良い）。幅による差は小さく、**B は幅 64 で十分**に見える（パラメータ 8,769、test 0.282、最速）。A は幅 128 が幅 64 より悪く、幅 256 が最良で、幅の順に並ばない。5 エポックで未収束（val がまだ下がっている）で、1 シードのばらつきが大きいとみられる。
5. **B の val は早く底を打つ**: B 幅 64 は 2 エポック目、幅 256 は 1 エポック目が最良で、その後 val は悪化し（幅 256 は 0.323 → 0.405）、train は下がり続けた。test の RMS は良く（B 幅 256 で 0.278）、val シナリオ（45 本）の偏りの可能性がある。本学習では早期終了（patience 5）に任せず、val を見て判断する。
6. **(d) は測り方を直して安定した**: 最初の測定は A 幅 64 が 130,676、B 幅 64 が 840,839 と不安定だった。原因は他のプロセスの割り込み（全回の値が、遅い側にだけ外れる）。ウォームアップを入れ、10 回のうち最速で判定する形に直すと、幅が大きいほど遅い自然な順になった（幅 64: 約 70 万、幅 128: 約 36〜39 万、幅 256: 約 15 万）。**幅 256 は限界値 145,000 ぎりぎり**で、中央値は 143,035〜144,791 と限界を割る。
7. **(b) の 4,000 ステップ**: B 幅 64（0.147°）と B 幅 256（0.148°）は解析モデル（0.156°）より小さい。8,000 ステップになると解析モデルより悪くなる。誤差は後半に増幅される。
