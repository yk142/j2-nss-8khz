# 計画 — NSS によるゲイン最適化と真値での検証（issue #39）

要件: `docs/requirements_gain_opt.md`（2026-10-25 ユーザー承認: 余裕の制約あり、しきい値は案のまま、負の対照あり、検証用ゲイン約 12 点＋最適点の ±10%）

## 手順
1. **NSS で走査**（`python/gain_opt.py scan`）: wn = 15·1.1^i（i = 0〜31、1.1 刻みなので「±10%」が格子点になる）× ζ = 0.5〜2.0（0.1 刻み 16 点）= 512 ゲイン ＋ 正規化用の (30, 1)。対象: B 幅 64 の 3 シード、A 幅 64 の 3 シード、解析モデル、負の対照（解析モデルの k を 0.9 倍）。各モデルで C4 の J と安定判定を出す。
2. **検証用ゲインの選定**（`gain_opt.py select`）: 各モデルの最適点（余裕あり・なし）、その wn ±10%、B の J 上位、ζ ∈ {0.7, 1, 1.5} での安定境界の前後を合わせる。
3. **真値で評価**（`tools/j2_flex_eval.m` に ゲイン一覧の引数を追加。C4 のみ。1 ゲイン約 2 分）。
4. **判定**（`gain_opt.py judge`）: 要件 §5 の基準 1〜5 と、負の対照。図: J の等高線（NSS と真値）、安定境界、最適点。
5. 結果を `docs/gain_opt_results.md` と `reports/issue-39/` にまとめる。

## 定義
- 余裕あり: (wn, ζ)、(wn/1.1, ζ)、(wn·1.1, ζ) がすべて安定。
- 後悔（regret）: 真値で、NSS の最適点の J と、真値で安定かつ余裕ありの評価済みゲインの最良 J の差 ÷ 最良 J。余裕なしの最適点は、真値で安定な評価済みゲインの最良 J と比べる。
- 真値の J は、既存の 21 ゲイン（`reports/issue-25/eval_C4.json`）の (30, 1) で正規化したもの。
