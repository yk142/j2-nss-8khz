# ゲイン違いの再現性 (c2) の結果 — 8 kHz NSS（issue #19）

2026-10-24。`docs/requirements_c2.md` の条件で、PD ゲイン 9 組（wn ∈ {15, 30, 60} rad/s × ζ ∈ {0.7, 1, 1.5}）× 条件 E1/E2 × PTP 12 軌道の真値（Simscape、216 本）と、NSS（採用 2 本: B w64 seed 2、A w256 seed 2、解析モデルも併記）の閉ループを比べた。指標・図: `reports/issue-19/c2_metrics.json`、`c2_cost.png`。評価は `python/evaluate_c2.py`、真値の生成は `tools/j2_gen_c2.m`。

## 結果: 合格

合否（Spearman(J) ≥ 0.9、かつ NSS の最適ゲインの真値の J が真値の最小の 5% 以内、かつ発散なし）は、**E1・E2 とも、B・A・解析モデルのすべてが合格**。

| 条件 | モデル | Spearman(J) | 最適ゲイン（真値は wn=60, ζ=1.5） | θ RMSE の真値との相対差（最大 / 平均） | J の相対差（最大） | 発散 |
|---|---|---|---|---|---|---|
| E1 | 解析モデル | 1.000 | 一致 | 3.4% / 1.6% | 0.9% | 0 |
| E1 | B w64 s2 | 1.000 | 一致 | 3.5% / 1.8% | 1.2% | 0 |
| E1 | A w256 s2 | 1.000 | 一致 | 1.7% / 0.7% | 1.0% | 0 |
| E2 | 解析モデル | 1.000 | 一致 | 3.2% / 1.4% | 0.6% | 0 |
| E2 | B w64 s2 | 1.000 | 一致 | 3.2% / 1.5% | 1.0% | 0 |
| E2 | A w256 s2 | 1.000 | 一致 | 2.1% / 1.0% | 1.1% | 0 |

真値の θ RMSE [°]（E1、gains の順: wn=15 の ζ=0.7/1/1.5、wn=30、wn=60）: 0.526, 0.476, 0.420 / 0.146, 0.135, 0.122 / 0.038, 0.036, 0.034。E2 もほぼ同じ。真値の J: 4.90, 4.53, 4.12 / 2.08, 2.00, 1.91 / 1.28, 1.27, 1.25。

- 順位は 9 点すべてで完全に一致した。隣り合う組の差が小さい wn=60 の 3 組（J 1.25〜1.28、差 1〜2%）の順位も、3 モデルとも合った。
- 補助指標の順位相関: θ RMSE・τ RMS・最大誤差は 1.000。整定時間は 0.93〜1.0（A・B の E1 が 0.933）。
- NSS の θ RMSE の真値との差は、3 モデルとも真値の 1〜4% 以内（最大 0.058°）。

## 事前予想との比較（issue #19 のコメント）

- 当たり: 順位相関は 0.9 を超え、最適は格子の端（wn=60）。θ の誤差の大きさ（wn=15 で 0.5° 前後、wn=60 で 0.03° 前後）も予想どおり。
- 外れ: A の絶対値が真値から 2〜5 割ずれる可能性と予想したが、実際は 2% 以内（B は 3.5% 以内）。閉ループでは、A の静止域のトルク差（5〜15 N·m）が、予想したほど θ の誤差に効かなかった。

## この結果が言えること・言えないこと

- 言えること: 剛体 J2 の PTP 追従で、wn 15〜60 rad/s、ζ 0.7〜1.5 の PD ゲインの優劣を、NSS（B・A）が真値と同じ順に並べ、値も 4% 以内で再現する。FF の係数誤差 ±15%・外乱 ±20 N·m の条件でも成り立つ。
- 言えないこと:
  - 最適ゲインは格子の端（wn=60、ζ=1.5）。J に高ゲインへの罰則（トルクのノイズ、弾性、遅れ）がなく、ゲインが高いほど良い単調なコストなので、「内側の最適点を見つけられる」ことは示していない
  - E1 と E2 は符号を反転した対称な条件で、結果はほぼ同じ（独立な 2 条件とは言えない）
  - 弾性（制振）、ゲイン以外の制御器、wn > 60 は評価していない
  - 評価したのは採用 2 本のみ（シードは 1 つ）
- 次の作業の候補: 内側に最適点を持つコスト（トルクの変化率・ノイズを入れた制御器、弾性プラント）の評価。真値の再生成が要る。
