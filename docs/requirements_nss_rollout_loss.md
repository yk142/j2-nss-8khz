# 要件定義（ドラフト）— 加速度状態 NSS のロールアウト損失との比較

作成: 2026-10-27 / issue #49 / 状態: **§6 を決定。実装・実験中**

前提: #45（基本形: (b)(c) 不合格）、#46（acc ノイズ学習 σ = 1.0 で (a)〜(d) 全合格）。

## 1. 目的

短い窓のロールアウト損失（K ステップ自己回帰）が、ノイズ学習に対してどれだけ上乗せになるかを測り、**計算負荷に見合うか**を判断する。特に B 幅 64 の水準（(b) 0.12°、(c) 0.022°）に近づくかを見る。

## 2. 現状（比較の基準、幅 64・20 エポック）

| 構成 | (b) [°] | (c) 最悪 [°] | 学習時間 |
|---|---|---|---|
| 基本形 σ = 0 | 18.7〜36.0 | 0.36〜0.41 | 約 15 分 |
| ノイズ σ = 1.0（3 シード） | 0.21〜0.24 | 0.032〜0.034 | 約 16 分 |
| （参考）B 幅 64 | 0.12 | 0.022 | — |

## 3. ロールアウト損失の設計（案）

- **窓**: 同じシナリオ内の連続する K + 1 行（K = 4, 16 など）。窓の先頭の acc は真値、以降の acc はモデル自身の出力。
- **損失**: K ステップ分の Δacc の誤差（標準化後の MSE）の平均。1 ステップ損失（K = 1）を含む。
- **pos / vel の扱い（2 案、要確認）**:
  - **案 1（教師強制）**: pos / vel は各ステップで真値を使い、acc だけを自己回帰にする。1 ステップ学習の仕様に最も近く、安い。
  - **案 2（自己回帰）**: acc と、そこから積分した vel / pos を自己回帰にする（トルクは真値）。評価時の挙動に近いが、θ = 0 の不安定性で勾配が大きくなりうる。
- **計算量**: 窓長 K に比例して 1 バッチの順伝播・逆伝播が増える（K = 16 で 1 エポック約 10 倍の見込み）。窓の数を減らす（サブサンプリング）ことで抑える。
- 実装: `train_nss_acc.py` に `--rollout-k`、`--rollout-frac`（窓を取る行の割合）を追加。評価・モデルは変更なし。

## 4. 実験（案）

幅 64・seed 0・20 エポック。A–C は基本形から、D は σ = 1.0 から。

| 記号 | 構成 |
|---|---|
| A | K = 4（案 1、窓 256） |
| B | K = 16（案 1、窓 128） |
| C | K = 16（案 2、窓 128） |
| D | K = 4（案 2、窓 256） |
| E | σ = 1.0 + 最良の構成（併用、A〜D の結果を見てから） |

有望なものを 3 シードに増やす。評価は (a)〜(d) と、1 エポックあたりの学習時間。

## 5. 判定

- 「ノイズ学習で十分」: D が σ = 1.0 に対して (b) と (c) で有意（シード間のばらつきを超える）に改善しない場合
- 「ロールアウト損失が有効」: (b) と (c) が B 幅 64 に近づき、学習時間の増加が許容範囲（目安: ノイズ学習の 3 倍以内）の場合

## 6. 決定事項（2026-10-27）

1. pos / vel の扱い: **案 1（教師強制）→ 案 2（自己回帰）の順に両方試す**（ユーザー指示）
2. 窓長 K: **お任せ** → 4 と 16。窓の数は K = 4 で 256、K = 16 で 128（計算量を 1 ステップ損失の約 2 倍に収めるため）
3. 学習時間の許容: **お任せ** → ノイズ学習（約 16 分）の **3 倍以内（約 50 分）**を目安にする
4. 案 2 の損失: acc 誤差に加え、真値からのずれ（dq, q）も損失に入れる。ずれは誤差の積分から求め、j ステップ目の成長（j·dt·e、(j²/2)·dt²·e）で割って acc 誤差と同じ大きさにそろえる。窓の先頭の acc は真値
5. 最良エポックは、1 ステップ検証損失 + ロールアウト検証損失（検証窓 2 万個、固定）で選ぶ

## 7. 範囲外

弾性（4 自由度）、シード 3 本を超える統計、窓長・σ の細かい最適化
