# 引継ぎ資料 — j2-state-data-gen から 8 kHz NSS へ

作成: 2026-10-22 / フォーク元: [j2-state-data-gen](https://github.com/yk142/j2-state-data-gen)（main = `834680a`、J2 単軸の学習データ生成〜学習・評価まで完了）

## 1. 新プロジェクトの目的（ユーザー情報の範囲）
- 対象: EPSON C8-A901S の **J2 単軸**。真値は **Simscape**（フォーク元と同じ構成）
- モデル: **NSS（Neural State Space）。制御器と同じ 8 kHz（Δt = 125 µs）で動作**
- 入力: トルク τ、角度 q、角速度 dq／出力: 各加速度（ddq）
- 構造: 残差型 `dx = f(u, x)`、`x1 = x + dx`（オイラー）
- 現状（別プロジェクト側）: **接触なし・純粋 MLP** で構築中
- 詳細（評価方法、目標精度、用途）は未確定 → §5

## 2. フォーク元の成果（再利用できるもの）
| 項目 | 内容 |
|---|---|
| プラント | J2 単軸 Simscape（`buildJ2Plant`）。URDF 後処理で他軸 fixed、J3=75.0684°。8 kHz `ode14x`。物理検証 13 件合格 |
| データ | 394 シナリオ（励振、姿勢保持、PTP、接触 56 本）。1 kHz で 2,856,681 遷移。**8 kHz の生データは `data/cache/`（git 管理外、215 MB、`q dq tau`、single）に保存済み**。再生成は 10/10 ビット一致 |
| 変換 | `j2Downsample(raw, fsIn, fsOut)`：状態は瞬時値の間引き、トルクは区間平均、`tauInst` に区間先頭の瞬時値。`fsOut=8000`（間引き率 1）は**未検証** |
| 出力 | `j2ExportFlat`：HDF5 / v7 mat |
| 学習 | `python/`：純粋 MLP（4→256×3→2、SiLU）、`ResidualNSM`（解析モデル＋NN 残差）、Adam、学習率 2e-3→1e-5、バッチ 4096、40 エポック |
| 評価 | 1 ステップ誤差（加速度換算 RMSE）、1 秒窓の開ループ、PTP 閉ループ（`python/j2nsm/evaluate_lib.py`） |

主な結果（1 kHz、1 シード、接触を含めて学習）: 接触なしの 1 ステップ RMSE は純粋 MLP 1.79 rad/s²、解析モデル 0.48。PTP 閉ループ誤差は純粋 MLP 0.086°、残差型 0.007°。詳細は `docs/training_report.md`、`docs/residual_report.md`。

**接触なしだけで学習した純粋 MLP（フォーク元 #28、PR #29、1 kHz、1 シード、同じ設定）**: `contact_*` と `atLimit` を train/val から除外。接触なしの 1 ステップ RMSE は 1.79 → **0.301**（解析モデル 0.481 を上回る）、1 秒窓の開ループ θ（1000 ステップ）は 2.39° → 0.847°（解析モデル 0.231°）、**PTP 閉ループ θ RMSE は 0.086° → 0.0114°**（12 本とも発散なし。範囲 0.0033〜0.0252°、解析モデル 0.0069°）。PTP の 1 ステップは 0.260（解析モデル 0.146）。接触の遷移は悪化（動的な接触 214.8）。つまり接触を除くだけで主ゲート（0.1° 以下）に 1 kHz で大きな余裕が出た。8 kHz では未検証。

## 3. 1 kHz → 8 kHz で変わること（導出。**未検証**を含む）
1. トルクの区間平均は不要。区間先頭の瞬時値 `tauInst` を入力にできる可能性（要確認）
2. オイラー位置更新（q1 = q + Δt·dq）の誤差上限 ≈ 0.5·Δt·（速度変化）。8 kHz なら最大でも約 0.018°（1 kHz は約 0.14°）
3. 1 ステップの変化が小さい（Δdq ≈ 2e-3 rad/s 以下、Δq ≈ 6e-4 rad 以下）。生データは single だが相対誤差 ≈ 1e-4 で許容範囲の見込み。標準化は必須
4. データ量は約 8 倍（約 2,290 万遷移）。同じエポック数なら CPU 学習は約 5 時間（要調整）
5. 1 秒窓のステップ数が 8 倍（8,000）。評価は引き続き**閉ループと短窓**。全長開ループ再生は不安定平衡（θ=0、成長率 約 3.5/s）で発散するので使わない

## 4. フォーク元から持ち込む教訓
- 作業サイクル：issue → ブランチ → 作業 → 報告 → ユーザー指示でコミット＋投稿 → ユーザー指示で PR → 承認。main へ直接 push しない。**PR の base は main**
- 弱い基準線との倍率を主張しない（強い基準線＝接触なしの解析モデル 0.48 と比べる）
- 純粋 MLP は 40 エポックで未収束（val 損失が下がり続けた）。解析モデルを土台にした残差型が大きく改善した
- 評価結果は PNG を `reports/issue-N/` にコミットし、SHA 固定の raw URL で issue に埋め込む。コミット後に rebase すると URL の SHA が変わる

## 5. 決定事項と未決事項
### 決定（2026-10-22）
1. **真値データ**：8 kHz の生データは**新規に生成**する（フォーク元の `data/cache/` は再利用せず、再現確認や比較の参照に使える）。接触なしに絞る
2. **f の形は 2 パターンを比べる**：(A) 純 NN `ddq = f(τ, q, dq)`、(B) 解析モデルの加速度 ＋ NN の残差 `ddq = a_phys(τ, q, dq) + f_NN(τ, q, dq)`。更新は `x1 = x + dx`（オイラー）
3. **評価の主ゲートは (c) 制御器に接続した PTP 閉ループ**（下記）。(a)(b)(d) は補助。**しきい値：PTP 12 本とも発散しない ＋ 真値との θ RMSE 0.1° 以下（決定）**
4. **トルクは区間平均**。8 kHz では 1 ステップ＝1 サンプルなので瞬時値と区別しなくてよい（印加トルクがステップ内で保持される前提。要確認）

### 未決（詰める）
1. **接触なしの絞り方**：`contact_*` 除外 ＋ `atLimit` 除外 ＋ `nearlimit` の扱い、新規シナリオ設計（励振・姿勢保持・PTP）、規模と生成時間
2. **入出力の定義**：q は生か sin/cos か。出力 ddq の標準化
3. **補助ゲート (a)(b)(d) のしきい値**（主ゲート (c) は決定済み。J2 版の純粋 MLP は 0.086° で余裕が小さい）
4. **学習設定**：エポック数、バッチ、学習率、モデル規模（8 kHz のデータ量に合わせる）、複数シード
5. ~~#28（フォーク元）~~：反映済み（§2）。8 kHz での再現は未検証

### 評価ゲート（J2 版の G0〜G3 と同じ位置づけ：フェーズ末尾の合否基準。**主ゲートは (c)**）
- (a) 1 ステップ ddq の RMSE が、強い基準線（接触なしの解析モデル）の ○ 倍以内
- (b) 1 秒窓の開ループ θ RMSE が ○° 以下
- (c) 制御器（8 kHz の PD＋FF）に接続した PTP 閉ループで、12 本とも発散せず θ 誤差 ○° 以下
- (d) 8 kHz のリアルタイム推論に収まる（1 ステップの計算時間 ＜ 125 µs）
- 目安（J2 版 1 kHz、純粋 MLP）：(a) 3.7 倍、(b) 2.39°（1 秒）、(c) 0.086°。残差型は (c) 0.007°
