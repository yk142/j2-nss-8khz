# 要件定義（ドラフト）— NSS によるゲイン最適化と真値での検証

作成: 2026-10-25 / issue #39 / 状態: **ドラフト（ユーザー確認待ち）**

前提: 弾性 NSS（#33、#37）、C4 の評価条件（#25: 1 kHz・1 ms 遅れのモータ角 PD）、(c3) の評価（#34）。

## 1. 目的

NSS のオフライン用途（制御ゲインの最適化、制振性能の事前評価）を実際にやり、**NSS で選んだゲインが真値でも良いか**を確かめる。(c3) は 21 点の格子での再現性の確認だった。最適化は、NSS の誤差が最大になる所（安定境界の近く）を探索するので、別の確認が要る。

## 2. #25 の真値から分かっていること（設計への入力）

- 真値で安定な 16 ゲインのうち、J が最小なのは **(wn, ζ) = (180, 0.7)**（J = 0.161）。次が (120, 0.7)、(90, 1) の順。
- 一方、(180, 1)、(180, 1.5)、(240, すべて) は持続振動（不安定）。**J の最適点は、不安定境界の隣にある。**
- したがって、NSS が境界の位置を数 % の精度で再現できないと、最適化は「境界の向こう側」を選びうる。ここが検証の山場。

## 3. 最適化の問題設定（案）

| 項目 | 案 | 理由 |
|---|---|---|
| 変数 | wn ∈ [15, 300] rad/s、ζ ∈ [0.5, 2.0]（Kp = M·wn²、Kd = 2ζ·M·wn） | #25 の格子（wn 15〜240、ζ 0.7〜1.5）を含み、外側にも余白 |
| 目的 | J = 追従 RMS と整定ねじりの正規化平均（#25 と同じ。(30, 1) の値で正規化） | 比較しやすい |
| 制約 | 安定（整定ねじり < 3e-5 rad、発散なし）。さらに**余裕**: wn を ±10% ずらした 2 点も安定 | 境界ぎりぎりのゲインは実機で使えない。余裕の定義は §7 で相談 |
| 探索方法 | NSS で細かい格子（wn 40 点 × ζ 15 点 = 600 ゲイン、対数刻み）を全評価し、上位を局所探索で詰める | 2 変数なので全探索で足りる。局所最小も見える |
| 軌道 | C4 と同じ PTP 6 本 | #25・#34 と同じ |
| 所要時間（NSS） | 約 30 分（21 ゲインで約 1 分） | 実測からの見積もり |

## 4. 検証（真値）

1. NSS の最適点と、NSS の J の上位から選んだ**検証用ゲイン約 12 点**（最適点の周囲、境界の手前と向こう側を含む）を、真値（Simscape）で C4 の評価をする。1 ゲイン × 6 軌道で約 2 分、計約 25 分。
2. `tools/j2_flex_eval.m` を、ゲインの一覧を引数にできるよう拡張する（今は wn・ζ の格子が固定）。
3. 比較する最適化器: **B 幅 64（3 シード）**、A 幅 64（3 シード）、解析モデルのみ。解析モデルの結果は、学習した NN が最適化に何を足すかの基準線になる。

## 5. 合格基準（案）

| # | 基準 | しきい値（案） |
|---|---|---|
| 1 | NSS の最適点は真値でも安定 | 3 シードとも安定 |
| 2 | 後悔（regret）: 真値での最適点の J と、検証用ゲインの中の真値の最良 J の差 | 最良の J の 10% 以内 |
| 3 | NSS の J と真値の J の相対誤差（最適点で） | 15% 以内 |
| 4 | 安定境界の位置: NSS が不安定と予測する最小の wn（ζ ごと）と真値の差 | 10% 以内 |
| 5 | シード間: 最適点の wn・ζ のばらつき | wn で 10% 以内 |

基準 2 が最も重要（「NSS で選んだゲインが、真値で選んだゲインと遜色ないか」）。

## 6. 負の対照（任意）

#34 で ρ が 0.38 になった「k を 10% ずらした解析モデル」で最適化し、**NSS の誤差が最適化にどう出るか**を見る。誤差の大きいモデルを使うと、真値で悪いゲインを選ぶことを確かめられれば、この検証の判別力の証拠になる。

## 7. 決めてほしいこと

1. **余裕の制約**を入れるか。入れる場合は、wn の ±10% で安定（案）か、ほかの定義か。入れない場合、最適点は不安定境界に接するので、基準 1 は厳しい。
2. **合格基準のしきい値**（§5）は案のままでよいか。
3. **負の対照（§6）**を行うか。
4. 検証用ゲインは、NSS の J の上位 + 境界の前後を含む約 12 点でよいか。

## 8. 範囲外

- 遅れの大きさ（1 ms 以外）・共振周波数・モデル誤差を変えた条件での最適化（今回は C4 の 1 条件）
- 実機での検証
- 最適化の方法そのもの（ベイズ最適化、勾配など）の比較。2 変数なので格子で足りる
