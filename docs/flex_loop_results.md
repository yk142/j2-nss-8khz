作成: 2026-10-24 / 要件: `docs/requirements_flex_loop.md`

## 2. 確認 3・4: ゲイン走査（PTP 3 本 `ptp_v40_003` `ptp_v60_002` `ptp_v80_003` の平均）

全 15 ゲインで発散なし。最大トルクの RMS は 117〜122 N·m でゲインにほぼよらない。

## 3. 解釈

- **確認 3**: wn=30, ζ=1 の追従は 3 本平均 0.036°（先に見た `ptp_v60_002` 単独は 0.038°）。
- **確認 4**: 追従・ねじりとも wn・ζ が大きいほど単調に小さい。**内部最適は出なかった**（最適は格子の端 wn=120, ζ=1.5）。
  - 線形解析では共振モードの減衰は wn=30〜60 で最大になり、それ以上で悪化すると予想した。しかし PTP 軌道の励起はフィードフォワードがねじりを打ち消すため小さく（ねじり RMS は 1e-3 rad 未満）、軌道追従の誤差が支配的になる。モード減衰の差が指標に出ていない。
  - 残留振動は 1e-4 rad 程度で、ゲイン間の差も小さく順位が揃わない（ノイズ的）。
- したがって、制振の観点でゲインの順位をつけるには、PTP + FF のままでは差が出にくい。外乱（衝撃）やモデル誤差（FF 係数ずれ、共振周波数のずれ）を加えた条件が必要。次の issue での検討事項。

## 4. 限界

- PTP 3 本のみ（(c2) の 12 本ではない）。
- FF は弾性モデルの公称値で作っており、モデル誤差なし。
- 共振周波数 20 Hz のみ。
- 走査の指標は上記 3 つで、コスト関数は未定義。
