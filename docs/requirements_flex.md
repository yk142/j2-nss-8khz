# 要件 — 制振用の真値プラント（減速機の弾性を入れた J2 二慣性モデル）

作成: 2026-10-24 / issue #21 / 状態: **確定（2026-10-24、ユーザー承認）**。

## 1. 目的と範囲

制振性能の事前評価（`docs/training_8khz.md` §7 の項目 1）に向けて、現行の剛体 1 軸の真値に**減速機のねじり弾性**を加えた J2 単軸プラント（Simscape）を作る。

- **この issue**: 弾性プラントの作成と、物理の検証まで（ユーザー決定）
- **次の issue（未着手）**: データ生成、NSS の入出力の再検討（弾性では状態が (q, dq) 2 つだけでは足りず、モータ側の状態が隠れる）、評価

## 2. モデル（ユーザー決定: 二慣性、PD はリンク角を見る）

```
 τ（制御トルク）→ [モータ側慣性 Jm, 角度 θm] —(ばね k・ダンパ c)— [リンク側 慣性 JL, 角度 θ, 重力・摩擦] 
```

| 項目 | 値 | 根拠 |
|---|---|---|
| Jm（モータ反映慣性） | 2.2896 kg·m² | 現行の armature（親資産 `c8_params`） |
| JL（リンク側慣性） | 3.7961 kg·m² | 現行の実効慣性 M（6.0857）− Jm。M = JL + Jm なので、剛体極限で現行の解析モデルと一致 |
| 共振周波数 | **20 Hz**（ユーザー決定。実機データなしの仮定値） | f = (1/2π)·√(k·(1/Jm + 1/JL)) |
| ねじりばね k | **22,553 N·m/rad** | 20 Hz から逆算（(2π·20)² / 0.70017） |
| ねじりダンパ c | **17.9 N·m·s/rad** | モードの減衰比 0.05（仮定）：c = 2·0.05·√(k·Jeq)、Jeq = Jm·JL/(Jm + JL) = 1.428 |
| 制御トルク | モータ側に入れる（トルク上限 ±860.4 N·m は現行どおり） | |
| 摩擦（Fc, Bv, ε） | リンク側（現行のまま） | 剛体極限で現行と一致させるため。モータ側・減速機側への分配は仮定が増えるので行わない |
| 重力 | リンク側（現行のまま） | |
| PD のフィードバック | **リンク角 θ・リンク角速度 dθ**（現行どおり） | デュアルエンコーダ相当。現行の評価と比べやすい |
| ばね・ダンパ | 線形（バックラッシュ・非線形ばねは入れない） | 仮定値のため、まず線形 |

出力: 現行どおり `q`（リンク角）、`dq` に加え、3 番目に `tauOut`（制御トルクの素通し）、4・5 番目に **`qm`（モータ角）、`dqm`** を追加。現行の剛体プラントの I/F は変えない（既存の剛体プラントを壊さない）。

## 3. 実装の方針

現行の J2 は、Rotational Multibody Interface（RMI）に 1-D の慣性（armature）を剛結合して反映慣性を表現している（`addC8Armature`）。弾性版はこの結合を、**RMI → ばね・ダンパ → モータ慣性**に置き換え、制御トルクを理想トルク源でモータ慣性に入れる。リンク側の関節には、RMI が返すばね・ダンパの反力だけが入る。新しい関数 `buildJ2FlexPlant`（`buildJ2Plant` を呼んだ後に後処理）で作り、`buildJ2Plant` は変更しない。

## 4. 検証項目（合否）

| # | 検証 | 方法 | 合格 |
|---|---|---|---|
| 1 | 剛体極限 | k を 100 倍・c を 10 倍にした弾性プラントと、現行の剛体プラントに同じトルクを入れて比較（開ループ、短い窓） | θ の差が剛体の θ の変化量の 1% 以内 |
| 2 | 共振周波数 | 静止（重力保持）付近で短いパルスを入れ、ねじり角 θm − θ の自由振動の周波数を FFT で求める | 20 Hz の ±5% |
| 3 | 減衰比 | 同じ自由振動の包絡線の減衰から減衰比を求める | 0.05 の ±30%（摩擦・粘性が加わるため幅を持たせる） |
| 4 | 静的なねじり | 一定トルクで静止させ、θm − θ を測る | 保持トルク／k と 5% 以内 |
| 5 | エネルギー | 摩擦なしの別条件（Fc = Bv = 0）で、外力なしの自由振動の力学エネルギーが減衰以外で増えない | 増加なし（ダンパのみで減少） |
| 6 | 数値の安定 | 8 kHz（ode14x）で、トルク上限までのステップ・チャープ入力でも発散・NaN なし | 発散なし |
