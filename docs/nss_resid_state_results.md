# 加速度を状態に持つ残差型 NSS（基本形）の剛体での評価 — issue #45

作成: 2026-10-27 / 要件: `docs/requirements_nss_resid_state.md`

## 1. 実施内容

別プロジェクトの仕様どおりの基本形（状態 acc = 直前の区間の加速度、NN 入力 `[acc, τ, q, dq]`、出力 Δacc、速度は前進オイラー・位置は台形則）を、剛体 J2（`j2_nss8k.h5`、train 13.2 M 遷移）で学習し、ゲート (a)〜(d) で評価した。幅 64、深さ 3、最後の層は 0 初期化。コードは `python/nss8kacc/`、`train_nss_acc.py`、`evaluate_nss_acc.py`。

## 3. 読み取り

1. **(a)(d) は合格、(b)(c) は不合格。** (a) は現行より良い（0.24〜0.28 倍）が、自己回帰では 4,000 ステップで 10〜36°、PTP 閉ループで 0.26〜0.41° の誤差。
2. 1 ステップ予測の良さは、前の加速度が強い手がかりになることによる（「加速度を変えない」予測だけで 0.20 rad/s²、解析モデルは 0.53）。動力学（重力・慣性・摩擦）を学ぶ圧力は弱く、自己回帰の精度は 1 ステップの精度と別。
3. **学習を長くすると少し良くなる**（20 → 60 エポックで (b) 18.7 → 10.2°、(c) 0.357 → 0.257°）が、検証 RMS は 0.14 rad/s² で頭打ち（9 エポック以降）。エポックの増加だけでは基準に届きにくい。
4. 閉ループの誤差（`reports/issue-45/plots/closed_loop_err_s0.png`）は、動き始めの 0.1〜0.5 秒で 0.2〜0.5° に立ち上がり、その後は発散せず ±0.5° の範囲に残る。解析モデルは ±0.02° 以下。
5. ロールアウトの誤差は、100 ステップで 0.02°（解析モデル 0.003°）、1,000 ステップで 1.9°（0.05°）と増え、θ = 0 まわりの不安定性で増幅される。

## 4. 限界・次

- 幅 64 のみ、seed 0〜2（60 エポックは seed 0 のみ）。解析モデルで初期化した最初の acc の影響は未切り分け。
- 次: アブレーション（幅 256、位置を `sin q, cos q` に、`τ_{k-1}` を状態に、Δpos・Δvel を NN に）。ロールアウト損失は計算負荷のため避ける。
