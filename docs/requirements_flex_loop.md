# 要件 — 弾性 J2 の PD 閉ループと、制振評価の設計（データ・NSS 入出力）

作成: 2026-10-24 / issue #23 / 状態: **確定（2026-10-24、ユーザー承認）**。

## 1. 事前の発見: リンク角フィードバックは不安定

#21 の弾性プラント（共振 20 Hz、ねじり減衰比 0.05）に、剛体と同じ PD（Kp = M·wn²、Kd = 2·ζ·M·wn、M = 6.0857）を**リンク角・リンク角速度**で掛けると、線形モデルの閉ループは不安定になる（モータを駆動してリンク側を見る非コロケーション制御の性質）。

| フィードバック | 共振モードの実部 [1/s]（wn = 5, 15, 30, 60, 90, 120、ζ = 1） | 結論 |
|---|---|---|
| リンク角・角速度 | −1.3, **+8.3, +21, +41, +57, +69** | wn ≳ 7 rad/s で不安定（現行の wn = 30 は不安定） |
| **モータ角・角速度（採用）** | −14.5, −30, −45, −18, −10, −7 | 全ゲインで安定。共振の減衰は wn = 30〜60 付近で最大、それより高いと悪化 |
| 位置: リンク角、速度: モータ角速度 | −14.5, −29.6, −32, −2.6, **+8.1, +15** | wn ≳ 60 で不安定 |

（線形化は重力・摩擦なし。ζ = 0.7, 1.5 でも同じ傾向。）**ユーザー決定: モータ角・モータ角速度をフィードバックする PD を採用**（実機の多くと同じコロケーション構成）。共振の減衰がゲインの内側で最大になるため、制振を含むコストでは**ゲインの内側に最適点が出る**見込み（#19 の単調なコストとの違い）。

## 2. 弾性用の閉ループ（この issue で実装）

```
τ = sat( τ_ff + τ_dist + Kp·(θm_ref − θm) + Kd·(dθm_ref − dθm) )     ±τ_peak（860.4 N·m）で飽和
```

- Kp = M·wn²、Kd = 2·ζ·M·wn（M = Jm + JL = 6.0857。剛体の PD と同じ式。wn・ζ は同じ意味で比べられる）
- FF は剛体の逆動力学（`j2Feedforward`: M·ddq_ref − mgL·sin θ_ref + Bv·dq_ref + Fc·tanh(dq_ref/ε)）をそのまま使う。剛体の運動を作るトルクなので、弾性の振動を打ち消さない（それが制振の評価対象）
- モータ角の参照: θm_ref = θ_ref + twist_ref、twist_ref = (τ_ff − Jm·ddq_ref)/k（剛体運動のときのばねのたわみ）。dθm_ref は θm_ref の数値微分
- 入力 `[θm_ref, dθm_ref, τ_ff, τ_dist]`、出力は #21 と同じ（q, dq, tauOut = 飽和後の実印加トルク, qm, dqm）
- 実装: `buildJ2FlexClosedLoop`（#21 の `buildJ2FlexPlant` に閉ループを足す）、`simJ2FlexLoop`（参照・FF の作成と実行）

## 4. データ生成の要件（次の issue で実装。ここでは設計を確定）

- 学習データは 8 kHz のまま、接触なし（`nss8k` と同じ考え方）。シナリオは `nss8k` を踏襲し、**弾性プラント**で再生成する（励振・hold・PTP のパターン、train/val/test/benchmark の分割は同じ）
- 共振（20 Hz）付近の励振を十分に含める: 励振パターンの周波数上限 fMax が 20 Hz を十分に超えること（現行の fMax の分布を確認し、不足なら追加）。振幅は共振で飽和・限界に当たらない範囲
- 閉ループのシナリオ（hold・PTP）は、**モータ角 PD（wn = 30、ζ = 1）**で生成する（現行と同じ設計値）
- 各遷移の記録: q, dq, qm, dqm, τ（モータ側へ入るトルク）。サンプルの次の 4 状態から ddq, ddqm を作る
- 規模は `nss8k` と同程度（約 1,900 万遷移、生成 約 4 時間）を目安とし、詳細は次の issue で確定

## 5. NSS の入出力の再設計（次の issue で実装。ここでは設計を確定）

| 項目 | 現行（剛体） | 弾性（案） |
|---|---|---|
| 状態 | (θ, dθ) | **(θ, dθ, θm, dθm)**（4 つ） |
| 入力 | [sin θ, cos θ, dθ/5.236, τ/860.4] | + [(θm − θ)/twist_scale, (dθm − dθ)/dtwist_scale]（ねじりとねじり速度。モータ角の絶対値は不要） |
| 出力 | ddθ（1 つ） | **ddθ, ddθm（2 つ）** |
| 更新 | 1 ステップのオイラー | 同じ（4 状態とも） |
| (B) 残差型の物理項 | 剛体の解析モデル | **二慣性の解析モデル**（Jm, JL, k, c、摩擦、重力）。ddθ, ddθm の両方に |
| 評価のゲート | (a)(b)(c)(d)（#16 で確定） | 同じ枠組み。(c) の閉ループは、モータ角 PD でリンク角の追従と、ねじり・残留振動を真値と比べる |

- 弾性では、モータ側の状態が隠れるため (θ, dθ, τ) だけの NSS は使えない。**モータ側の状態を NSS の状態に含める**（シミュレータの内部状態なので、評価時に観測不要。学習データは真値から取れる）。
- ゲイン最適化のコスト（次の評価）: 追従 RMS、リンクの残留振動（停止後のねじり・リンク角の振れ）、トルク RMS の重み付き和を案とし、結果を見る前に確定する。
